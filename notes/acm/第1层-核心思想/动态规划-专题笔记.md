## 〇、一句话总纲

★ **DP = 把「大问题」拆成「重叠的小问题」，每个小问题只算一次，存起来复用。**

```
朴素递归：fib(5) 重复算 fib(3) 好几次 → O(2^n)
DP：      fib(3) 算一次存起来        → O(n)
```

★★ **一句话：DP = 递归 + 记忆化（或等价的递推）。**

---

## 〇·补、★ DP 三要素（= 递归三问）

| 递归三问 | DP 三问 | 含义 |
|---|---|---|
| dfs(参数) 返回什么？ | **状态** `dp[i]` 表示什么？ | 小问题的答案含义 |
| 出口？ | **边界** `dp[0] = ?` | 最小子问题的答案 |
| `dfs(n) = f(dfs(n-1))` | **转移方程** `dp[i] = g(dp[i-1])` | 大问题怎么用小问题算 |

★ **你已经会写递归 → 已经会写 DP，只是换个写法。**

### 两个写法

```cpp
// A. 递推（自底向上）
for (int i = 2; i <= n; i++) dp[i] = ...;

// B. 记忆化搜索（自顶向下，递归 + 缓存）
int memo[n+1]; fill(memo, memo+n+1, -1);
int dfs(int i) {
    if (i <= 1) return 1;
    if (memo[i] != -1) return memo[i];        // ★ 已算过
    return memo[i] = dfs(i-1) + dfs(i-2);     // ★ 算完存
}
```

★ **建议：先用记忆化搜索（沿用递归思维），熟练后转递推。**

## 〇·补2、★ 怎么找状态（最关键的技能）

### 三个问句

**第 1 问：「答案」是什么？**
```
看题目要返回什么 → dp 的某个值就是它
```

**第 2 问：把「固定目标」变成「一族子问题」**
```
「凑出 11」 → 「凑出 i」（i = 0..11）
→ dp[i] = 凑出 i 的最少硬币数
```

**第 3 问：验证「能不能从更小的 dp 推出来」**
```
问「最后一步是什么」→ 能推出转移 → 状态对了
推不出来 → 状态缺信息（加维度 / 加约束）
```

### 三种常见状态形态

| 套路 | 形态 | 适用 |
|---|---|---|
| **目标量当状态** | `dp[i]` = 凑出 i / 到 i 阶 | 一维数值目标（70 / 322）|
| **位置当状态** | `dp[i]` = 前 i 个 / 以 i 结尾 | 序列类（53 / 198 / 300）|
| **两个量当状态** | `dp[i][j]` = 前 i 个 vs 前 j 个 / 容量 j | 背包 / 双序列（1143 / 416）|

### ★★ 状态设计的分水岭：「前 i 个」vs「以 i 结尾」

| | 「前 i 个最优」 | 「以 i 结尾最优」 |
|---|---|---|
| 适用约束 | **禁止型**（不能相邻）| **连续型**（必须相连）|
| 能否直接接 `nums[i]` | ❌ 不确定（丢失结束位置）| ✅ 一定能 |
| 答案 | `dp[n]` | **`max(所有 dp[i])`** |
| 例 | 打家劫舍（198）| 最大子数组和（53）、LIS（300）|

★★ **判据：约束是「禁止某些组合」→ 前 i 个；约束是「必须相连」→ 以 i 结尾。**

★ **更本质：状态必须包含「影响后续决策的所有信息」。**

## 一、★ 五种转移形态（核心）

### 形态 1：固定前驱（O(n)）

```cpp
// 70 爬楼梯
dp[i] = dp[i-1] + dp[i-2];

// 198 打家劫舍
dp[i] = max(dp[i-1], nums[i-1] + dp[i-2]);

// 53 最大子数组和（以 i 结尾）
dp[i] = nums[i] + max(0, dp[i-1]);
```

★ **特点：只看前 1~2 个 → O(n)，可滚动数组优化到 O(1)。**

### 形态 2：枚举前驱（O(n²)）

```cpp
// 300 LIS
for (int i = 1; i < n; i++)
    for (int j = 0; j < i; j++)
        if (nums[j] < nums[i])
            dp[i] = max(dp[i], dp[j] + 1);
```

★ **特点：每个 i 要看所有 j → O(n²)。**

### 形态 3：完全背包（物品无限用 → 内层**正序**）

```cpp
// 322 零钱兑换
dp[0] = 0;
for (int i = 1; i <= amount; i++)
    for (int x : coins)
        if (i >= x && dp[i-x] != -1)
            dp[i] = min(dp[i], dp[i-x] + 1);
```

★ **正序：`dp[i-x]` 读的是「本轮已更新」的值 → 等价于可以重复用。**

### 形态 4：0-1 背包（物品最多一次 → 内层**倒序**）

```cpp
// 416 分割等和子集
vector<bool> dp(target + 1, false);
dp[0] = true;
for (int x : nums)
    for (int j = target; j >= x; j--)         // ★ 倒序
        dp[j] = dp[j] || dp[j-x];
```

★★ **倒序：保证 `dp[j-x]` 是「上一轮」的值 → 每个物品最多用一次。**

### 形态 5：二维双序列（O(mn)）

```cpp
// 1143 LCS
if (text1[i-1] == text2[j-1])
    dp[i][j] = dp[i-1][j-1] + 1;              // 相等 → 配对消耗
else
    dp[i][j] = max(dp[i-1][j], dp[i][j-1]);   // 不等 → 抛弃一个
```

★ **每个格子依赖左 / 上 / 左上。**

### ★ 五形态速查

| 形态 | 内层 | 复杂度 | 代表 |
|---|---|---|---|
| 固定前驱 | — | O(n) | 70 / 198 / 53 |
| 枚举前驱 | `for j < i` | O(n²) | 300 |
| 完全背包 | **正序** | O(n·m) | 322 |
| 0-1 背包 | **倒序** | O(n·m) | 416 |
| 双序列 | 二维表 | O(mn) | 1143 |

## 一·补、★ 背包两兄弟：正序 vs 倒序（最容易错）

★★ **这是 0-1 背包 vs 完全背包的唯一区别，也是最高频的坑。**

```cpp
// 0-1 背包：每个物品最多一次 → 倒序
for (int x : items)
    for (int j = target; j >= x; j--)      // ★ 从大到小
        dp[j] = dp[j] || dp[j-x];

// 完全背包：物品无限次 → 正序
for (int x : items)
    for (int j = x; j <= target; j++)      // ★ 从小到大
        dp[j] = dp[j] || dp[j-x];
```

### ★ 为什么倒序才对（0-1 背包）

```
nums = [1], target = 2

正序：
  j=1: dp[1] = dp[1] || dp[0] = true      ← 用了 1 一次
  j=2: dp[2] = dp[2] || dp[1] = true      ← ★ dp[1] 本轮刚变 true
                                            → 等于「又用了一次 1」
  → 错误地说「能凑出 2」

倒序：
  j=2: dp[2] = dp[2] || dp[1] = false     ← dp[1] 还是上一轮的 false
  j=1: dp[1] = dp[1] || dp[0] = true
  → 正确地说「凑不出 2」✓
```

★★ **倒序保证 `dp[j-x]`（下标更小）**还没被本轮修改** → 读到的是「上一轮」的值。**

### 记忆口诀

```
0-1 背包：倒序 —— 不能重复用，从后往前，避免踩到自己刚改的
完全背包：正序 —— 可以重复用，从前往后，正大光明地踩
```

### ★ 注意：322 零钱兑换的写法是「外层金额、内层硬币」

```cpp
for (int i = 1; i <= amount; i++)          // 外层：金额
    for (int x : coins)                     // 内层：面额
        dp[i] = min(dp[i], dp[i-x] + 1);
```

★ **这样写「内层不涉及顺序问题」** —— 因为外层是金额，`dp[i-x]` 天然是已算好的。

★ **另一种写法（外层物品、内层金额）才是「正序 vs 倒序」的场景** —— 求**方案数**时要注意顺序是否有意义。

## 一·补2、★★ 状态机 DP（多状态 / 多维度）

### ★ 1. 什么是状态机 DP

普通 DP 的 `dp[i]` 只说「前 i 个的最优值」。当**同一时刻实体有多份互斥身份**（空仓 / 持仓、上锁 / 解锁），
两份最优值不同、并且每天互相迁移时，就要**多开一个状态维度**去记。

```
dp[i][0] = 第 i 天结束、空仓的最大现金
dp[i][1] = 第 i 天结束、持仓的最大现金（可为负，表示垫付成本）
```

★★ **纪律：状态 = 身份（空仓/持仓），不是动作（买/卖）。** 买卖是**状态之间的边**，不是节点。

### ★ 2. 三条判据（不满足就别硬套）

| # | 条件 | 反例 |
|---|---|---|
| ① | 每个时刻实体有 **≥2 种互斥身份** | 只有一个状态 → 退化为普通 `dp[i]` |
| ② | 身份每天按规则**迁移**（买、卖、等）| 身份不变 → 不需要状态机 |
| ③ | 目标是**某个终态**上的最优值 | 目标不分终态 → 用普通 DP |

★ **反例检验：121 只允许一次交易 → 状态图是一条链（空仓 → 持仓 → 空仓），没有分叉**，
所以一个 `minPrice` 变量就够（扫描型贪心），不需要状态机。
→ 状态机 DP 的真正入门是 **122**（无限次交易，状态图有环）。

### ★★ 3. 限制三分法：加状态 / 加维度 / 不加

★ **这是股票系列五道题的统一视角（122 / 309 / 714 / 123 / 188）。**

| 限制类型 | 处理方式 | 写法 | 例子 |
|---|---|---|---|
| 行为的**成本**（手续费）| **状态数不变**，转移里扣钱 | `dp[i][1] = dp[i-1][0] - p - fee` | 714 |
| 行为的**时机**（卖完不能立刻买）| **新增一个状态**记住「刚做过」 | 状态数 2 → 3 | 309 |
| 行为的**总次数** | **新增一维**记次数 | `dp[n][2][k+1]` | 123 / 188 |

★ **一句话：**「我此刻是谁」→ 加状态；「我还能用多少」→ 加维度。

### ★ 4. 次数维度 `k` 的更新：（只在买入时 `k-1`）

```cpp
dp[i][k][0] = max( dp[i-1][k][0],              // 昨天就空仓
dp[i-1][k][1] + p );        // 今天卖 —— k 不变！

dp[i][k][1] = max( dp[i-1][k][1],              // 昨天就持仓
dp[i-1][k-1][0] - p );      // 今天买 —— k-1 → k
```

★ **“一笔”的口径：买 + 卖 算一笔，在买入时消耗配额。**

| 动作 | k 变化 | 在哪体现 |
|---|---|---|
| 买 | `k-1 → k` | 右式下标写 `k-1` |
| 卖 | 不变 | 右式下标写 `k` |
| 不动 | 不变 | 右式下标写 `k` |

⚠️ **不是 `k++`** —— 循环变量 `k` 是「当前讨论的状态」，不是计数器；所有信息都在下标里。

### ★★ 5. 计数型维度的 `0` 层是边界，不进循环

```cpp
for (int i = 1; i < n; i++) {
    dp[i][0][0] = 0;                 // ★ 0 笔、空仓：边界态，恒为 0
dp[i][1][0] = INT_MIN / 2;       // ★ 0 笔、持仓：不可达，必须封死
for (int k = 1; k <= K; k++) {   // ★ 从 1 开始
        ...
    }
}
```

★ **结构上和 0-1 背包的 `dp[0] = 0` 一模一样：**

```
0-1 背包：dp[0] = 0（边界），j 从 w 遍历
这里：    dp[·][·][0] = 边界，k 从 1 遍历
```

⚠️ **本人卡点（123）**：`k` 循环从 1 开始 → `dp[i][1][0]` 从未被赋值 → 靠 `vector` 默认 0 蒙过。
能过是因为 `k=0` 层从不被读；若扩成 `k=0..K`，非法状态立刻污染答案。

### ★★ 6. 参数化维度必须做退化检查（188 的考点）

★ **当维度上限由输入给出（188 的 `k`），先问：这个维度大到什么程度会失效？**

```
一笔交易至少占 2 天（买 + 卖）→ n 天最多 ⌊n/2⌋ 笔
k ≥ ⌊n/2⌋  →  次数限制失效  →  退化为 122（无限次）
```

```cpp
if (k >= n / 2) {                         // ★ 必须在建表之前
    int ans = 0;
    for (int i = 1; i < n; i++) ans += max(0, prices[i] - prices[i-1]);
    return ans;
}
```

★ **贪心为什么成立（拆解论证，一句话证明）**：

> 一笔长交易 `p[b] - p[a]` = 中间所有相邻差之和 `Σ (p[i] - p[i-1])`。
> 所以「拆成每天一买一卖」收益不变 → 取所有正相邻差即达上界。

★ **反例检验（必走）**：

```
prices = [1, 2, 1, 2], k = 1
  贪心（差分求和）= 2 笔交易、收益 2
  正确答案（k=1）= 1 买 2 卖 = 1
  → 贪心错！所以分界必须严格按 n/2，不能凭感觉
```

⚠️ **不特判的后果**：`k+1` 巨大 → MLE；`O(n·k)` → TLE；`k` 小时答案也可能错。

### ★ 7. 终态纪律

★ **终态 = 目标身份那个状态，不是 `max(所有状态)`。**

| 题 | 终态 | 理由 |
|---|---|---|
| 122 / 714 / 123 / 188 | `dp[n-1][0]` 或 `max_k dp[n-1][k][0]` | 持仓 = 钱没落袋，排除 |
| 309 | `max(dp[n-1][0], dp[n-1][2])` | ★ 两个都是空仓（已卖），只是冷冻是否结束 |

★ **判据**：终态 = 「**现金已落袋且手上无货**」的所有状态。持仓类全部排除。

### ★ 8. 非法状态初值：给负无穷，不给 0

```cpp
dp[0][0] = 0;                   // 0 笔、空仓：合法
dp[0][1] = -prices[0];          // 0 天买入：合法
dp[0][2] = INT_MIN / 2;         // ★ 第 0 天不可能「刚卖」：非法
```

⚠️ **用 `INT_MIN/2` 而非 `INT_MIN`** —— 转移里有 `+ prices[i]`，用 `INT_MIN` 会下溢。

### ★ 9. 「来源数」决定 `=` 还是 `max`

```
dp[i][j] 的来源有 1 个  →  dp[i][j] = 唯一来源            （309 的 dp[i][2]）
dp[i][j] 的来源有 ≥2 个 →  dp[i][j] = max(各来源)         （其余全部）
```

★ 机械全写 `max` 不会错，但**也不会发现自己漏了或多了来源**。
309 的 `dp[i][2] = dp[i-1][1] + cur`（唯一来源，用 `=`）就是全题最精妙的一行。

## 二、★ 什么时候能用 DP（三个条件）

| 条件 | 含义 | 反例 |
|---|---|---|
| **① 最优子结构** | 大问题的最优解包含小问题的最优解 | 凑零钱贪心（局部推不出全局）|
| **② 重叠子问题** | 小问题会被重复用到 | 归并排序（子问题不重叠）|
| **③ 无后效性** | 状态确定后，后续只依赖它，不依赖「怎么来的」| 需要记录路径的问题 |

★ **判据：能写出「状态 + 转移」→ DP。**

## 三、案例（本人独立完成）

### 3.1 爬楼梯（70）—— 一维线性

```cpp
int climbStairs(int n) {
    if (n <= 2) return n;
    int prev2 = 1, prev1 = 2;              // dp[1], dp[2]
    for (int i = 3; i <= n; i++) {
        int cur = prev1 + prev2;
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

★ **状态**：`dp[i]` = 到 i 阶方法数；**转移**：`dp[i] = dp[i-1] + dp[i-2]`；**边界**：`dp[1]=1, dp[2]=2`。
★ **本质：斐波那契数列。** 也可视为「完全背包求方案数」的特例。

---

### 3.2 打家劫舍（198）—— 选择型（偷/不偷）

```cpp
int rob(vector<int>& nums) {
    int prev2 = 0, prev1 = 0;              // dp[i-2], dp[i-1]
    for (int x : nums) {
        int cur = max(prev1, prev2 + x);   // 不偷 vs 偷
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

★ **状态**：`dp[i]` = **前 i 间**最优
★ **转移**：`dp[i] = max(dp[i-1], nums[i-1] + dp[i-2])`
★ **为什么偷了能用 `dp[i-2]`**：偷了 i 就禁 i-1，能自由选的范围正好是「前 i-2 间」

---

### 3.3 最大子数组和（53）—— 连续约束

```cpp
int maxSubArray(vector<int>& nums) {
    int dp_pre = nums[0], best = nums[0];
    for (int i = 1; i < nums.size(); i++) {
        dp_pre = nums[i] + max(0, dp_pre);  // ★ 前面为负就丢掉
        best = max(best, dp_pre);
    }
    return best;
}
```

★ **状态**：`dp[i]` = **以 i 结尾**的最大和
★ **转移**：`dp[i] = nums[i] + max(0, dp[i-1])`
★ **答案**：`max(所有 dp[i])`（不是 `dp[n-1]`）

⚠️ **为什么必须「以 i 结尾」**：「前 i 个最优」丢失了「结束位置」→ 无法判断能否接上 → 不连续。

### 3.4 零钱兑换（322）—— 完全背包

```cpp
int coinChange(vector<int>& coins, int amount) {
    vector<int> dp(amount + 1, -1);
    dp[0] = 0;
    for (int i = 1; i <= amount; i++) {
        int best = INT_MAX;
        for (int x : coins)
            if (i >= x && dp[i-x] != -1)
                best = min(best, dp[i-x]);
        if (best != INT_MAX) dp[i] = best + 1;
    }
    return dp[amount];
}
```

★ **状态**：`dp[i]` = 凑 i 的最少硬币数
★ **转移**：`dp[i] = min over coins (dp[i-x]) + 1`
★ **`-1` 表示「凑不出」**，和「0 枚」区分

### 3.5 最长递增子序列（300）—— 枚举前驱

```cpp
int lengthOfLIS(vector<int>& nums) {
    int n = nums.size(), ans = 1;
    vector<int> dp(n, 1);                   // ★ 自己单独 = 1
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++)
            if (nums[j] < nums[i])
                dp[i] = max(dp[i], dp[j] + 1);
        ans = max(ans, dp[i]);
    }
    return ans;
}
```

★ **状态**：`dp[i]` = **以 i 结尾**的 LIS 长度
★ **转移**：`dp[i] = 1 + max(dp[j])` for `j < i && nums[j] < nums[i]`
★ **答案**：`max(所有 dp)`

★ **进阶**：O(n log n) 用「贪心 + 二分」（维护 tails 数组），属于另一条思路。

### 3.6 分割等和子集（416）—— 0-1 背包

```cpp
bool canPartition(vector<int>& nums) {
    int sum = 0;
    for (int x : nums) sum += x;
    if (sum % 2) return false;              // ★ 奇数不可能

    int target = sum / 2;
    vector<bool> dp(target + 1, false);
    dp[0] = true;
    for (int x : nums)
        for (int j = target; j >= x; j--)   // ★ 倒序
            dp[j] = dp[j] || dp[j - x];
    return dp[target];
}
```

★ **第一步：问题转化** ——「分成两个和相等的子集」⟺「能否选出一些数和 = sum/2」
★ **状态**：`dp[j]` = 能否凑出和 j
★ **转移**：`dp[j] = dp[j] || dp[j-x]`（不用 x / 用 x）

### 3.7 最长公共子序列（1143）—— 二维双序列

```cpp
int longestCommonSubsequence(string text1, string text2) {
    int m = text1.size(), n = text2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            if (text1[i-1] == text2[j-1])
                dp[i][j] = dp[i-1][j-1] + 1;              // 相等：配对消耗
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);   // 不等：抛弃一个
    return dp[m][n];
}
```

★ **状态**：`dp[i][j]` = text1 前 i 个 vs text2 前 j 个的 LCS
★ **答案在右下角** `dp[m][n]`（注意和 53/300 不同）

★ **二维表的几何：**

```
    j-1   j
i-1  ①   ②
i    ③   ④        ④ 依赖 ①②③
```

### 3.8 买卖股票的最佳时机 II（122）—— 状态机 DP（首个）

★ **概念 / 判据 / 限制三分法见 `§一·补2`**（那里有完整框架）。本节只记本题实例。

```cpp
int maxProfit(vector<int>& prices) {
    int n = prices.size();
    if (n == 0) return 0;
    // dp[i][0] 第 i 天结束后，未持有股票的最大收益
    // dp[i][1] 第 i 天结束后，持有股票的最大收益
    vector<vector<int>> dp(n, vector<int>(2));
    dp[0][0] = 0;
    dp[0][1] = -prices[0];
    for (int i = 1; i < n; i++) {
        int cur = prices[i];
        dp[i][0] = max(dp[i - 1][1] + cur, dp[i - 1][0]);   // 今天卖 / 今天空着
        dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] - cur);   // 今天不动 / 今天买
    }
    return dp[n - 1][0];                                    // ★ 终态 = 空仓
}
```

★ **121 vs 122 的分水岭（一句话）**：

```
121:  dp[i][1] = max(dp[i-1][1],        - p)      ← 买之前 dp0 必为 0（只买一次）
122:  dp[i][1] = max(dp[i-1][1], dp[i-1][0] - p)  ← 从任意空仓来（卖完可再买）
```

→ 差别就在 `dp[i-1][0]` 这一项。这一项在 121 里恒为 0 所以可省，在 122 里**不能省**。

★ **122 还有贪心解**：`Σ max(0, p[i]-p[i-1])`。它和状态机 DP 同结果，
但**在 123（限制次数）上就失效**（贪心可能用掉超额笔数，反例见 188 节）。

⚠️ **本人踩坑**：
- `dp[0][1] = -prices[0]` 前**没判 `n == 0`** → 空数组越界（第 3 次犯类型 A）
- 返回值写成 `max(dp[n-1][0], dp[n-1][1])` → 逻辑上 `dp[..][1] ≤ dp[..][0]` 结果不错，
  但**终态语义应为空仓**，直接 `return dp[n-1][0]`
- ★ **本人偏好：不做空间优化** —— `dp[n][2]` 保留整张表，可打印、可单步、新增状态只加一维下标；
  滚动变量可读性差、易串味（`ndp0`/`ndp1` 忘用临时变量就用到了当天的值）

### 3.9 最佳买卖股票时机含冷冻期（309）—— 状态数 2 → 3

★ **限制类型：行为的【时机】** → 加**状态**（不是加维度）。

```cpp
int maxProfit(vector<int>& prices) {
    int n = prices.size();
    if (n == 0) return 0;
    // dp[i][0] 空仓，且「明天可以买」
    // dp[i][1] 持仓
    // dp[i][2] 空仓，且「今天刚卖出」→ 明天必须冷冻
    vector<vector<int>> dp(n, vector<int>(3));
    dp[0][0] = 0;
    dp[0][1] = -prices[0];
    dp[0][2] = INT_MIN / 2;                 // ★ 第 0 天不可能「刚卖」
    for (int i = 1; i < n; i++) {
        int cur = prices[i];
        dp[i][0] = max(dp[i - 1][0], dp[i - 1][2]);      // ① 空着 / 冷冻结束
        dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] - cur); // ② 持仓 / 今天买（冷冻不能买）
        dp[i][2] = dp[i - 1][1] + cur;                   // ③ ★ 唯一来源，用 =
    }
    return max(dp[n - 1][0], dp[n - 1][2]);              // ★ 两个都是空仓
}
```

★ **三状态语义边界（最关键）**：

| 状态 | 含义 | 来源数 | 写法 |
|---|---|---|---|
| `dp[i][0]` | 空仓、可买（今天没卖）| 2 | `max` |
| `dp[i][1]` | 持仓 | 2 | `max` |
| `dp[i][2]` | 空仓、今天刚卖（明天冷冻）| **1** | **`=`** |

★★ **为什么 `dp[i][2]` 用 `=` 而不是 `max`**：「今天卖」是唯一来源，
没有「昨天就刚卖」这种继承（昨天的冷冻是 `dp[i-1][2]`，那是另一个状态）。
**机械全写 `max` 不会错，但也不会发现自己漏了/多了来源。**

★ **必需的两条“不能”**（否则冷冻期形同虚设）：

```
dp[i][0] 不能从 dp[i-1][1] 来   ← 那是「今天卖」，卖完进冷冻，不是「可买」
dp[i][1] 不能从 dp[i-1][2] 来   ← 昨天冷冻，今天买不了
```

⚠️ **本人踩的坑（类型 G，语义混乱）**：
- 一开始把 `dp[i][2]` 当成「是否冻结」的 **0/1 标志位**，卡了半天
- ★ **错误本质**：dp 格子的值必须是**目标值（收益）**，「身份」由**下标**承载
- 同类错误：542 把 `mat` 的 `1` 改成 `0` 当 visited，但 `0` 本义是源点
- ★ **自检问句**：「我这个 dp 格子存的是目标值吗？」答不上来 → 状态定义没落地
- 初值曾写 `dp[0][2] = 0`（非法状态给了 0）→ 碰巧 `dp[1][0] = max(0, 0) = 0` 不露馅；
  现已改 `INT_MIN / 2`，语义才正确

### 3.10 买卖股票的最佳时机含手续费（714）—— 状态数不变

★ **限制类型：行为的【成本】** → **状态数不变**，只在转移里扣钱。

```cpp
int maxProfit(vector<int>& prices, int fee) {
    int n = prices.size();
    if (n == 0) return 0;
    // dp[i][0] 空仓 / dp[i][1] 持仓
    vector<vector<int>> dp(n, vector<int>(2));
    dp[0][0] = 0;
    dp[0][1] = -prices[0] - fee;            // ★ 初值必须含 fee
    for (int i = 1; i < n; i++) {
        int cur = prices[i];
        dp[i][0] = max(dp[i - 1][0], dp[i - 1][1] + cur);        // 卖：不扣
        dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] - cur - fee);  // 买：扣一次
    }
    return dp[n - 1][0];
}
```

★★ **「一次买入卖出，只收一次」的语义**：

```
The transaction fee is only charged once | for each stock purchase and sale.
                    ↑ 只收一次         ↑ 对「每一次买+卖的组合」而言
```

★ `purchase and sale` 是**一个整体**（一次完整回合），不是两件各收。

| 写法 | 转移 | 结果 |
|---|---|---|
| **扣在买**（推荐）| `dp[i][1] = dp[i-1][0] - p - fee` | ✅ 每笔交易恰好扣一次 |
| 扣在卖 | `dp[i][0] = dp[i-1][1] + p - fee` | ✅ 与上方**数值等价**（终态必平仓）|
| ❌ 两边都扣 | 两个转移都 `- fee` | ❌ 扣了两次，答案偏小 |

★ **为什么推荐扣在买**：若题目允许最终持仓，该持仓「只买未卖」——
扣在买已付过 fee，语义一致；扣在卖则该持仓是「毛价」，语义别扭。

⚠️ **本人自查点**：
- `dp[0][1]` 忘写 `- fee` → 第 0 天买入的路径少算一次手续费，答案偏大
- 两边都 `- fee` → 一笔交易扣两次

### 3.11 买卖股票的最佳时机 III（123）—— 第一次加维度

★ **限制类型：行为的【总次数】** → 加**维度 `dp[n][2][K+1]`**。

```cpp
int maxProfit(vector<int>& prices) {
    int n = prices.size();
    if (n == 0) return 0;
    // ★ 本人下标习惯：dp[i][持仓 0/1][已用笔数 0..2]
    vector<vector<vector<int>>> dp(n, vector<vector<int>>(2, vector<int>(3)));

    // 初值：只有 (空仓,0笔) 和 (持仓,1笔) 可达
    dp[0][0][0] = 0;
    dp[0][1][1] = -prices[0];
    dp[0][1][0] = INT_MIN / 2;
    dp[0][0][1] = INT_MIN / 2;
    dp[0][0][2] = INT_MIN / 2;
    dp[0][1][2] = INT_MIN / 2;

    for (int i = 1; i < n; i++) {
        dp[i][0][0] = 0;                       // ★ k=0 是边界，不进循环
        dp[i][1][0] = INT_MIN / 2;
        for (int k = 1; k <= 2; k++) {         // ★ 从 1 开始
            dp[i][0][k] = max(dp[i - 1][0][k], dp[i - 1][1][k] + prices[i]);        // 卖：k 不变
            dp[i][1][k] = max(dp[i - 1][1][k], dp[i - 1][0][k - 1] - prices[i]);    // 买：k-1 → k
        }
    }

    int ans = INT_MIN;
    for (int x : dp[n - 1][0]) ans = max(ans, x);   // 只取空仓，k 取最大
    return ans;
}
```

⚠️ **本人卡点：`k` 遍历**

```
疑问：「k 有 3 个值，为什么循环只转 2 次？k = 0 那层去哪了？」
→ 计数型维度的 k = 0 是【边界态】，只有初值，不参与循环
→ 结构上和 0-1 背包的 dp[0] = 0 一模一样
```

⚠️ **致命细节**：若 `k` 循环从 1 开始而**没显式填** `dp[i][1][0]`，
`vector` 默认初始化为 `0` → 非法状态「0 笔 + 持仓 = 0」潜伏。
本题因为 `k=0` 层从不被读而蒙过；一旦扩成 `k=0..K` 立刻污染答案。

★ **反例检验：能不能拆成「两段各自跑 122」？**

```
prices = [1, 100, 2, 101]，正确答案 198（两笔各 99）
t=0: 前[1] → 0    后[100,2,101] → 99    合计 99
t=1: 前[1,100] → 99   后[2,101] → 99   合计 198  ✓
t=2: 前[1,100,2] → 99  后[101] → 0       合计 99
```

★ **拆法是合法替代解（k=2 时 O(n²)）**，但：

| k | 拆法 | 状态机 |
|---|---|---|
| 2 | `O(n²)` 可接受 | `O(n·2)` |
| 10 | `O(n¹⁰)` 爆炸 | `O(n·10)` |
| 参数 k | ❌ | ✅ |

★ **判据**：拆法在 `k=2` 成立是**前提恰好成立**（段间无耦合），
不是算法普适。→ 归入 `算法边界与正确性.md §〇·补` 的**【前提破坏】**档。

### 3.12 买卖股票的最佳时机 IV（188）—— 参数化维度 + 退化检查

★ **123 的直接推广**，但多一个**考点**：`k` 由输入给出 → 必须先做**退化检查**。

```cpp
int maxProfit(int k, vector<int>& prices) {
    int n = prices.size();
    if (n == 0) return 0;

    // ★★ 退化检查：一笔占 2 天 → 最多 ⌊n/2⌋ 笔
    //    k ≥ ⌊n/2⌋ → 次数限制失效 → 退化为 122（无限次）
    if (k >= n / 2) {
        int ans = 0;
        for (int i = 1; i < n; i++) ans += max(0, prices[i] - prices[i - 1]);
        return ans;
    }

    vector<vector<vector<int>>> dp(n, vector<vector<int>>(2, vector<int>(k + 1)));  // ★ k+1 不是 k

    // 初值：只有 (空仓,0笔) 和 (持仓,1笔) 可达
    for (int hold = 0; hold <= 1; hold++) {
        for (int j = 0; j <= k; j++) {
            if (hold == 0 && j == 0) dp[0][hold][j] = 0;
            else if (hold == 1 && j == 1) dp[0][hold][j] = -prices[0];
            else dp[0][hold][j] = INT_MIN / 2;
        }
    }

    for (int i = 1; i < n; i++) {
        dp[i][0][0] = 0;
        dp[i][1][0] = INT_MIN / 2;
        for (int x = 1; x <= k; x++) {
            dp[i][0][x] = max(dp[i - 1][0][x], dp[i - 1][1][x] + prices[i]);
            dp[i][1][x] = max(dp[i - 1][1][x], dp[i - 1][0][x - 1] - prices[i]);
        }
    }

    int ans = INT_MIN;
    for (int x : dp[n - 1][0]) ans = max(ans, x);
    return ans;
}
```

★★ **退化时贪心为什么成立（拆解论证 = 一句话证明）**：

> 一笔长交易 `p[b] - p[a]` = 中间所有相邻差之和 `Σ(p[i] - p[i-1])`。
> 所以「一笔赚 4」与「4 笔各赚 1」**收益完全相同** → 取所有正相邻差即达上界。

★ **上界 + 可达**：任何策略收益 = 若干相邻差之和 ≤ `Σ max(0, Δ)`；
每天都「昨天买今天卖」（只在上浨日做）→ 恰好取到上界。

⚠️ **反例检验（必走）—— 贪心不能无限用**：

```
prices = [1, 2, 1, 2], k = 1
  贪心 = (2-1) + (2-1) = 2 笔交易，收益 2
  正确（k=1）= 1 买 2 卖 = 1
  → 贪心错！所以分界必须严格按 n/2，不能凭感觉
```

★ **两件事要分清（因果链）**：

```
不是「因为 k 大所以贪心对」
而是 k ≥ n/2 → 次数限制失效 → 问题变成 122 → 122 的贪心在此成立
```

⚠️ **不特判的后果**：`k+1` 巨大 → MLE；`O(n·k)` → TLE；`k` 小时答案也可能错。
★ 这是【前提破坏】的典型：「`k` 是有效维度」的前提被破坏了。

| 15 | 次数维度 `k` 在卖出时也 `+1` | **只在买入时 `k-1→k`**，卖出 `k` 不变 |
| 11 | 状态机 DP 终态取 `max(所有状态)` | 终态必须是**目标身份**（如股票题 = 空仓）|
| 12 | 状态机 DP 状态初值设为 0 | 非法状态要给**负无穷**（如持仓初值 `-prices[0]`）|

## 六、一句话总结

> ★ **DP = 递归 + 记忆化；三要素 = 状态 / 转移 / 边界。**
>
> ★ **找状态：把「答案」的目标量变成变量；验证：问「最后一步」，能推出转移就对了。**
>
> ★ **★ 状态设计分水岭：**
> - **禁止型约束**（不能相邻）→ 「前 i 个」→ 答案 `dp[n]`
> - **连续型约束**（必须相连）→ 「以 i 结尾」→ 答案 `max(dp)`
>
> ★ **五种转移形态**：固定前驱 O(n) / 枚举前驱 O(n²) / 完全背包（正序）/ 0-1 背包（**倒序**）/ 双序列二维。
>
> ★ **背包唯一区别：0-1 倒序，完全正序。**
>
> ★ **二维 DP 答案在右下角；一维「以 i 结尾」答案要取 max。**
>
> ★ **状态机 DP**：同一时刻有多份**互斥身份**且每天互迁时，多开一个状态维度；
> 终态必须是**目标身份**，不是 `max(所有状态)`。
> 入门顺序：**122（2 状态）→ 309（3 状态）→ 714（+成本）→ 123 / 188（+次数维度）**。
>
> ★★ **限制三分法（股票系列统一视角）**：
> - **成本**（手续费）→ 状态数不变，转移里扣钱
> - **时机**（冷冻期）→ **加状态**
> - **次数** → **加维度**
>
> ★★ **计数型维度的 `0` 层是边界，不进循环**（和 0-1 背包的 `dp[0]=0` 同一套路）。
>
> ★★ **参数化维度必须做退化检查**：`k >= n/2` → 退化为 122 贪心（拆解论证），
> 且判断要放在**建表之前**。
>
> ★ **「来源数 1 → 用 `=`，来源数 ≥2 → 用 `max`」** —— 机械全写 `max` 不会错，但也不会发现自己漏了来源。

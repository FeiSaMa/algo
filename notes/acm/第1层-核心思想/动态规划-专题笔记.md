## 〇、一句话总纲

★ **DP = 把「大问题」拆成「重叠的小问题」，每个小问题只算一次，存起来复用。**

```
朴素递归：fib(5) 重复算 fib(3) 好几次 → O(2^n)
DP：      fib(3) 算一次存起来        → O(n)
```

★★ **一句话：DP = 递归 + 记忆化（或等价的递推）。**

---

## 〇·补、★ DP 三要素（= 递归三问）

| 递归三问 | DP 三问 | 含义 |
|---|---|---|
| dfs(参数) 返回什么？ | **状态** `dp[i]` 表示什么？ | 小问题的答案含义 |
| 出口？ | **边界** `dp[0] = ?` | 最小子问题的答案 |
| `dfs(n) = f(dfs(n-1))` | **转移方程** `dp[i] = g(dp[i-1])` | 大问题怎么用小问题算 |

★ **你已经会写递归 → 已经会写 DP，只是换个写法。**

### 两个写法

```cpp
// A. 递推（自底向上）
for (int i = 2; i <= n; i++) dp[i] = ...;

// B. 记忆化搜索（自顶向下，递归 + 缓存）
int memo[n+1]; fill(memo, memo+n+1, -1);
int dfs(int i) {
    if (i <= 1) return 1;
    if (memo[i] != -1) return memo[i];        // ★ 已算过
    return memo[i] = dfs(i-1) + dfs(i-2);     // ★ 算完存
}
```

★ **建议：先用记忆化搜索（沿用递归思维），熟练后转递推。**

## 〇·补2、★ 怎么找状态（最关键的技能）

### 三个问句

**第 1 问：「答案」是什么？**
```
看题目要返回什么 → dp 的某个值就是它
```

**第 2 问：把「固定目标」变成「一族子问题」**
```
「凑出 11」 → 「凑出 i」（i = 0..11）
→ dp[i] = 凑出 i 的最少硬币数
```

**第 3 问：验证「能不能从更小的 dp 推出来」**
```
问「最后一步是什么」→ 能推出转移 → 状态对了
推不出来 → 状态缺信息（加维度 / 加约束）
```

### 三种常见状态形态

| 套路 | 形态 | 适用 |
|---|---|---|
| **目标量当状态** | `dp[i]` = 凑出 i / 到 i 阶 | 一维数值目标（70 / 322）|
| **位置当状态** | `dp[i]` = 前 i 个 / 以 i 结尾 | 序列类（53 / 198 / 300）|
| **两个量当状态** | `dp[i][j]` = 前 i 个 vs 前 j 个 / 容量 j | 背包 / 双序列（1143 / 416）|

### ★★ 状态设计的分水岭：「前 i 个」vs「以 i 结尾」

| | 「前 i 个最优」 | 「以 i 结尾最优」 |
|---|---|---|
| 适用约束 | **禁止型**（不能相邻）| **连续型**（必须相连）|
| 能否直接接 `nums[i]` | ❌ 不确定（丢失结束位置）| ✅ 一定能 |
| 答案 | `dp[n]` | **`max(所有 dp[i])`** |
| 例 | 打家劫舍（198）| 最大子数组和（53）、LIS（300）|

★★ **判据：约束是「禁止某些组合」→ 前 i 个；约束是「必须相连」→ 以 i 结尾。**

★ **更本质：状态必须包含「影响后续决策的所有信息」。**

## 一、★ 五种转移形态（核心）

### 形态 1：固定前驱（O(n)）

```cpp
// 70 爬楼梯
dp[i] = dp[i-1] + dp[i-2];

// 198 打家劫舍
dp[i] = max(dp[i-1], nums[i-1] + dp[i-2]);

// 53 最大子数组和（以 i 结尾）
dp[i] = nums[i] + max(0, dp[i-1]);
```

★ **特点：只看前 1~2 个 → O(n)，可滚动数组优化到 O(1)。**

### 形态 2：枚举前驱（O(n²)）

```cpp
// 300 LIS
for (int i = 1; i < n; i++)
    for (int j = 0; j < i; j++)
        if (nums[j] < nums[i])
            dp[i] = max(dp[i], dp[j] + 1);
```

★ **特点：每个 i 要看所有 j → O(n²)。**

### 形态 3：完全背包（物品无限用 → 内层**正序**）

```cpp
// 322 零钱兑换
dp[0] = 0;
for (int i = 1; i <= amount; i++)
    for (int x : coins)
        if (i >= x && dp[i-x] != -1)
            dp[i] = min(dp[i], dp[i-x] + 1);
```

★ **正序：`dp[i-x]` 读的是「本轮已更新」的值 → 等价于可以重复用。**

### 形态 4：0-1 背包（物品最多一次 → 内层**倒序**）

```cpp
// 416 分割等和子集
vector<bool> dp(target + 1, false);
dp[0] = true;
for (int x : nums)
    for (int j = target; j >= x; j--)         // ★ 倒序
        dp[j] = dp[j] || dp[j-x];
```

★★ **倒序：保证 `dp[j-x]` 是「上一轮」的值 → 每个物品最多用一次。**

### 形态 5：二维双序列（O(mn)）

```cpp
// 1143 LCS
if (text1[i-1] == text2[j-1])
    dp[i][j] = dp[i-1][j-1] + 1;              // 相等 → 配对消耗
else
    dp[i][j] = max(dp[i-1][j], dp[i][j-1]);   // 不等 → 抛弃一个
```

★ **每个格子依赖左 / 上 / 左上。**

### ★ 五形态速查

| 形态 | 内层 | 复杂度 | 代表 |
|---|---|---|---|
| 固定前驱 | — | O(n) | 70 / 198 / 53 |
| 枚举前驱 | `for j < i` | O(n²) | 300 |
| 完全背包 | **正序** | O(n·m) | 322 |
| 0-1 背包 | **倒序** | O(n·m) | 416 |
| 双序列 | 二维表 | O(mn) | 1143 |

## 一·补、★ 背包两兄弟：正序 vs 倒序（最容易错）

★★ **这是 0-1 背包 vs 完全背包的唯一区别，也是最高频的坑。**

```cpp
// 0-1 背包：每个物品最多一次 → 倒序
for (int x : items)
    for (int j = target; j >= x; j--)      // ★ 从大到小
        dp[j] = dp[j] || dp[j-x];

// 完全背包：物品无限次 → 正序
for (int x : items)
    for (int j = x; j <= target; j++)      // ★ 从小到大
        dp[j] = dp[j] || dp[j-x];
```

### ★ 为什么倒序才对（0-1 背包）

```
nums = [1], target = 2

正序：
  j=1: dp[1] = dp[1] || dp[0] = true      ← 用了 1 一次
  j=2: dp[2] = dp[2] || dp[1] = true      ← ★ dp[1] 本轮刚变 true
                                            → 等于「又用了一次 1」
  → 错误地说「能凑出 2」

倒序：
  j=2: dp[2] = dp[2] || dp[1] = false     ← dp[1] 还是上一轮的 false
  j=1: dp[1] = dp[1] || dp[0] = true
  → 正确地说「凑不出 2」✓
```

★★ **倒序保证 `dp[j-x]`（下标更小）**还没被本轮修改** → 读到的是「上一轮」的值。**

### 记忆口诀

```
0-1 背包：倒序 —— 不能重复用，从后往前，避免踩到自己刚改的
完全背包：正序 —— 可以重复用，从前往后，正大光明地踩
```

### ★ 注意：322 零钱兑换的写法是「外层金额、内层硬币」

```cpp
for (int i = 1; i <= amount; i++)          // 外层：金额
    for (int x : coins)                     // 内层：面额
        dp[i] = min(dp[i], dp[i-x] + 1);
```

★ **这样写「内层不涉及顺序问题」** —— 因为外层是金额，`dp[i-x]` 天然是已算好的。

★ **另一种写法（外层物品、内层金额）才是「正序 vs 倒序」的场景** —— 求**方案数**时要注意顺序是否有意义。

## 二、★ 什么时候能用 DP（三个条件）

| 条件 | 含义 | 反例 |
|---|---|---|
| **① 最优子结构** | 大问题的最优解包含小问题的最优解 | 凑零钱贪心（局部推不出全局）|
| **② 重叠子问题** | 小问题会被重复用到 | 归并排序（子问题不重叠）|
| **③ 无后效性** | 状态确定后，后续只依赖它，不依赖「怎么来的」| 需要记录路径的问题 |

★ **判据：能写出「状态 + 转移」→ DP。**

## 三、案例（本人独立完成）

### 3.1 爬楼梯（70）—— 一维线性

```cpp
int climbStairs(int n) {
    if (n <= 2) return n;
    int prev2 = 1, prev1 = 2;              // dp[1], dp[2]
    for (int i = 3; i <= n; i++) {
        int cur = prev1 + prev2;
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

★ **状态**：`dp[i]` = 到 i 阶方法数；**转移**：`dp[i] = dp[i-1] + dp[i-2]`；**边界**：`dp[1]=1, dp[2]=2`。
★ **本质：斐波那契数列。** 也可视为「完全背包求方案数」的特例。

---

### 3.2 打家劫舍（198）—— 选择型（偷/不偷）

```cpp
int rob(vector<int>& nums) {
    int prev2 = 0, prev1 = 0;              // dp[i-2], dp[i-1]
    for (int x : nums) {
        int cur = max(prev1, prev2 + x);   // 不偷 vs 偷
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

★ **状态**：`dp[i]` = **前 i 间**最优
★ **转移**：`dp[i] = max(dp[i-1], nums[i-1] + dp[i-2])`
★ **为什么偷了能用 `dp[i-2]`**：偷了 i 就禁 i-1，能自由选的范围正好是「前 i-2 间」

### 3.3 最大子数组和（53）—— 连续约束

```cpp
int maxSubArray(vector<int>& nums) {
    int dp_pre = nums[0], best = nums[0];
    for (int i = 1; i < nums.size(); i++) {
        dp_pre = nums[i] + max(0, dp_pre);  // ★ 前面为负就丢掉
        best = max(best, dp_pre);
    }
    return best;
}
```

★ **状态**：`dp[i]` = **以 i 结尾**的最大和
★ **转移**：`dp[i] = nums[i] + max(0, dp[i-1])`
★ **答案**：`max(所有 dp[i])`（不是 `dp[n-1]`）

⚠️ **为什么必须「以 i 结尾」**：「前 i 个最优」丢失了「结束位置」→ 无法判断能否接上 → 不连续。

### 3.4 零钱兑换（322）—— 完全背包

```cpp
int coinChange(vector<int>& coins, int amount) {
    vector<int> dp(amount + 1, -1);
    dp[0] = 0;
    for (int i = 1; i <= amount; i++) {
        int best = INT_MAX;
        for (int x : coins)
            if (i >= x && dp[i-x] != -1)
                best = min(best, dp[i-x]);
        if (best != INT_MAX) dp[i] = best + 1;
    }
    return dp[amount];
}
```

★ **状态**：`dp[i]` = 凑 i 的最少硬币数
★ **转移**：`dp[i] = min over coins (dp[i-x]) + 1`
★ **`-1` 表示「凑不出」**，和「0 枚」区分

### 3.5 最长递增子序列（300）—— 枚举前驱

```cpp
int lengthOfLIS(vector<int>& nums) {
    int n = nums.size(), ans = 1;
    vector<int> dp(n, 1);                   // ★ 自己单独 = 1
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++)
            if (nums[j] < nums[i])
                dp[i] = max(dp[i], dp[j] + 1);
        ans = max(ans, dp[i]);
    }
    return ans;
}
```

★ **状态**：`dp[i]` = **以 i 结尾**的 LIS 长度
★ **转移**：`dp[i] = 1 + max(dp[j])` for `j < i && nums[j] < nums[i]`
★ **答案**：`max(所有 dp)`

★ **进阶**：O(n log n) 用「贪心 + 二分」（维护 tails 数组），属于另一条思路。

### 3.6 分割等和子集（416）—— 0-1 背包

```cpp
bool canPartition(vector<int>& nums) {
    int sum = 0;
    for (int x : nums) sum += x;
    if (sum % 2) return false;              // ★ 奇数不可能

    int target = sum / 2;
    vector<bool> dp(target + 1, false);
    dp[0] = true;
    for (int x : nums)
        for (int j = target; j >= x; j--)   // ★ 倒序
            dp[j] = dp[j] || dp[j - x];
    return dp[target];
}
```

★ **第一步：问题转化** ——「分成两个和相等的子集」⟺「能否选出一些数和 = sum/2」
★ **状态**：`dp[j]` = 能否凑出和 j
★ **转移**：`dp[j] = dp[j] || dp[j-x]`（不用 x / 用 x）

### 3.7 最长公共子序列（1143）—— 二维双序列

```cpp
int longestCommonSubsequence(string text1, string text2) {
    int m = text1.size(), n = text2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            if (text1[i-1] == text2[j-1])
                dp[i][j] = dp[i-1][j-1] + 1;              // 相等：配对消耗
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);   // 不等：抛弃一个
    return dp[m][n];
}
```

★ **状态**：`dp[i][j]` = text1 前 i 个 vs text2 前 j 个的 LCS
★ **答案在右下角** `dp[m][n]`（注意和 53/300 不同）

★ **二维表的几何：**

```
    j-1   j
i-1  ①   ②
i    ③   ④        ④ 依赖 ①②③
```

### 3.9 买卖股票的最佳时机 II（122）—— 状态机 DP（首个）

```cpp
int maxProfit(vector<int>& prices) {
    int n = prices.size();
    if (n == 0) return 0;
    // dp[i][0] 第 i 天结束后，未持有股票的最大收益
    // dp[i][1] 第 i 天结束后，持有股票的最大收益
    vector<vector<int>> dp(n, vector<int>(2));
    dp[0][0] = 0;
    dp[0][1] = -prices[0];
    for (int i = 1; i < n; i++) {
        int cur = prices[i];
        dp[i][0] = max(dp[i - 1][1] + cur, dp[i - 1][0]);   // 今天卖 / 今天空着
        dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] - cur);   // 今天不动 / 今天买
    }
    return dp[n - 1][0];                                    // ★ 终态 = 空仓
}
```

★ **什么是状态机 DP**：普通 DP 的 `dp[i]` 只说「前 i 个的最优值」；当同一时刻实体有多份**互斥身份**
（空仓 / 持仓），两份最优值不同、并且每天互相迁移，就用**多一个状态维度**去记。

★ **三条判据（不满足就别硬套）**：

| # | 条件 | 本题 |
|---|---|---|
| 1 | 每个时刻实体有 **≥2 种互斥身份** | 空仓 / 持仓 ✅ |
| 2 | 身份每天按规则**迁移**（买、卖、等）| ✅ |
| 3 | 目标是**某个终态**上的最优值 | 最后一天空仓 ✅ |

★ **反例检验**：只有一个状态时，「状态机」退化为普通 `dp[i]`，多此一举。
例如 **121 只允许一次交易 → 状态图是一条链（空仓 → 持仓 → 空仓），没有分叉**，
所以一个 `minPrice` 变量就够，不需要二维状态。

★ **121 vs 122 的分水岭（一句话）**：

```
121:  dp[i][1] = max(dp[i-1][1],        - p)   ← 买之前 dp0 必为 0（只买一次）
122:  dp[i][1] = max(dp[i-1][1], dp[i-1][0] - p)  ← 从任意空仓来（卖完可再买）
```

→ 差别就在 `dp[i-1][0]` 这一项。这一项在 121 里恒为 0 所以可省，在 122 里**不能省**。

★ **122 还有贪心解**：把相邻差分为正的全加起来（`max(0, p[i]-p[i-1])` 求和）。
它和状态机 DP 同结果，但**123（最多 2 次）上就失效**（要限制交易段数）。

⚠️ **本人踩坑**：
- `dp[0][1] = -prices[0]` 前**没判 `n == 0`** → 空数组越界（第 3 次犯类型 A）
- 返回值写成 `max(dp[n-1][0], dp[n-1][1])` → 逻辑上 `dp[..][1] ≤ dp[..][0]` 结果不错，
  但**终态语义应为空仓**，直接 `return dp[n-1][0]`
- ★ **本人偏好：不做空间优化** —— `dp[n][2]` 保留整张表，可打印、可单步、新增状态只加一维下标；
  滚动变量可读性差、易串味（`ndp0`/`ndp1` 忘用临时变量就用到了当天的值）

### 3.8 七题横向对比

| 题 | 状态 | 转移 | 答案位置 | 复杂度 |
|---|---|---|---|---|
| 70 爬楼梯 | `dp[i]` 到 i 阶 | `dp[i-1] + dp[i-2]` | `dp[n]` | O(n) |
| 198 打家劫舍 | **前 i 间** | `max(dp[i-1], x + dp[i-2])` | `dp[n]` | O(n) |
| 53 最大子数组 | **以 i 结尾** | `x + max(0, dp[i-1])` | **max(dp)** | O(n) |
| 322 零钱 | 凑 i 元 | `min(dp[i-x]) + 1` | `dp[amount]` | O(n·m) |
| 300 LIS | **以 i 结尾** | `1 + max(dp[j])` | **max(dp)** | **O(n²)** |
| 416 分割 | 能否凑 j | `dp[j] \|\| dp[j-x]` **倒序** | `dp[target]` | O(n·m) |
| 1143 LCS | **前 i vs 前 j** | 相等 `+1`，不等 `max` | **`dp[m][n]`** | O(mn) |
| 122 股票 II | **第 i 天空仓/持仓** | 状态机双状态互迁 | **`dp[n-1][0]`**（终态）| O(n) |

## 四、⚠️ 避坑清单

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | **`dp[i]` 和 `nums[i-1]` 混用** | `dp` 通常开 `n+1`，`dp[i]` 对应 `nums[i-1]` |
| 2 | **答案写 `dp[n-1]` 但状态是「以 i 结尾」** | 用 `max(所有 dp)` |
| 3 | **0-1 背包内层写成正序** | **倒序**（否则变成无限用）|
| 4 | **「前 i 个」用于连续约束题** | 连续题必须用「以 i 结尾」 |
| 5 | **边界没设**（`dp[0]` 是多少）| 先写边界再写循环 |
| 6 | **`n == 0` / `n == 1` 越界** | 特判 |
| 7 | 二维 DP 用 `dp[i][j]` 但读 `text1[i]` | 应为 `text1[i-1]` |
| 8 | LCS 相等时用 `dp[i-1][j]` | 应为 `dp[i-1][j-1]`（两个都消耗）|
| 9 | LCS 不等时取单个 | 必须 `max(上, 左)` |
| 10 | 忘记「问题转化」 | 如 416 先转成「能否凑 sum/2」 |
| 11 | 状态机 DP 终态取 `max(所有状态)` | 终态必须是**目标身份**（如股票题 = 空仓）|
| 12 | 状态机 DP 状态初值设为 0 | 非法状态要给**负无穷**（如持仓初值 `-prices[0]`）|

## 六、一句话总结

> ★ **DP = 递归 + 记忆化；三要素 = 状态 / 转移 / 边界。**
>
> ★ **找状态：把「答案」的目标量变成变量；验证：问「最后一步」，能推出转移就对了。**
>
> ★ **★ 状态设计分水岭：**
> - **禁止型约束**（不能相邻）→ 「前 i 个」→ 答案 `dp[n]`
> - **连续型约束**（必须相连）→ 「以 i 结尾」→ 答案 `max(dp)`
>
> ★ **五种转移形态**：固定前驱 O(n) / 枚举前驱 O(n²) / 完全背包（正序）/ 0-1 背包（**倒序**）/ 双序列二维。
>
> ★ **背包唯一区别：0-1 倒序，完全正序。**
>
> ★ **二维 DP 答案在右下角；一维「以 i 结尾」答案要取 max。**
>
> ★ **状态机 DP**：同一时刻有多份**互斥身份**且每天互迁时，多开一个状态维度；
> 终态必须是**目标身份**，不是 `max(所有状态)`。
> 入门顺序：**122（2 状态）→ 309（3 状态）→ 714（+成本）→ 123 / 188（+次数维度）**。

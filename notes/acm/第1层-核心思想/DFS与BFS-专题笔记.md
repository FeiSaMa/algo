## 〇、一句话总纲

★ **DFS 和 BFS 都是「遍历」——探遍所有可达的状态，区别只在「探的顺序」。**

```
DFS：一条路走到黑，走不通再回头（栈 / 递归）
BFS：一层层往外扩散（队列）
```

★ **核心判据：**

| 问什么 | 用哪个 |
|---|---|
| 「能不能到达」「有多少种方案」「所有路径」 | **DFS** |
| **「最短步数」「最少操作」** | **BFS** |

★ **为什么最短用 BFS**：BFS 按「距离 1、2、3…」的顺序扩展 → **第一次到达目标时，步数一定最少**。

---

## 〇·补、★ 遍历的统一框架（本层最重要的认知）

★ **BFS / DFS 不是两种「算法」，而是「同一个遍历框架 + 不同的取策略」。**

```cpp
待处理集 = { 起点 };
while (待处理集 非空) {
    取一个节点 cur;        // ★ 唯一的区别：怎么取
    处理 cur;
    把 cur 的未访问邻居放进去;
}
```

| 取策略 | 底层结构 | 名字 |
|---|---|---|
| **取最早进来的**（FIFO）| 队列 | **BFS** |
| **取最晚进来的**（LIFO）| 栈 | **DFS** |

### ★ 「层序」差异的真正来源

★ **关键瞬间：处理完 B 后，待处理集里同时有两层。**

```
        A
       / \
      B   C
     / \
    D   E

处理完 A: 待处理 = {B, C}       （层 1）
处理完 B: 待处理 = {C, D, E}
                    ↑  ↑
                  层1  层2   ← ★ 混合状态！
```

| 结构 | 先出谁 | 结果 |
|---|---|---|
| **队列** | **C**（早入队）| C 是层 1 → **层 1 清完才进层 2** → BFS |
| **栈** | **D**（晚入栈）| D 是层 2 → **跳进层 2，C 被压着** → DFS |

★ **这就是「BFS 用队列、DFS 用栈」的底层原因 —— 不是约定，是「取策略」决定的。**

### ★ 同一族的其他算法（只是换了容器）

| 取策略 | 容器 | 算法 |
|---|---|---|
| 取最早（FIFO）| 队列 | **BFS**（无权最短路）|
| 取最晚（LIFO）| 栈 | **DFS** |
| 取最早 + 双端处理 0/1 边 | `deque` | **0-1 BFS** |
| **取距离最小** | `priority_queue`（小顶）| **Dijkstra**（带权最短路）|
| 取「估价最优」| `priority_queue` | **A\*** |

★★ **换数据结构 = 换遍历顺序 = 换算法。**

★ **这个视角的用处**：以后遇到新搜索算法，只问一句「**它从待处理集里怎么取？**」就理解了。

### ★ 副作用：递归就是「隐式用栈」

```cpp
void dfs(node) { visit(node); dfs(left); dfs(right); }
```

★ 函数调用栈 = 栈 → **后进的调用先返回 = LIFO = DFS**。

★ **所以「递归版 DFS」和「显式 stack 的 DFS」是同一件事**，后者只是把隐式栈写成显式。

## 一、递归基础（DFS 的地基）

### 1.1 递归三要素

```cpp
返回类型 dfs(状态) {
    if (终止条件) return ...;        // ① 出口
    for (每个分支) {                  // ② 分解
        dfs(子状态);                  // ③ 递归
    }
}

### ★ 1.1.1 什么时候选递归（四个判据）

★ **判据 1：问题结构呈「树形 / 自相似」**
```
整体 = 若干同构的更小整体
二叉树       → 左子树、右子树都是树         ✓
数组分区间   → 左半、右半都是数组           ✓
全排列       → 选完第一个数，剩下是同样问题 ✓
```

★ **判据 2：答案能由「子答案」组合出来（最关键）**

> **问自己：「如果我已经知道所有子问题的答案，我这一层能算出我的答案吗？」**

| 题 | 子问题 | 组合方式 |
|---|---|---|
| 二叉树最大深度 | 左深度、右深度 | `1 + max(左, 右)` |
| 阶乘 | `(n-1)!` | `n * (n-1)!` |
| 全排列 | 选完第一个后的排列 | 拼上前缀 |
| 翻转二叉树 | 翻转后的左右子树 | 交换左右 |

★ **判据 3：有明确的「最小子问题」（出口）**
```
二叉树 → 空节点，深度 0
全排列 → 路径满了，记录答案
阶乘   → n=1，返回 1
```
★ **找不到出口 → 递归写不出来（或会死）。**

★ **判据 4（负面）：循环层数是否由输入决定**
```
固定 3 层循环 → for for for 就行，不用递归
层数 = n（输入决定）→ 只能递归（或手动模拟栈）
```

### ★ 1.1.2 怎么思考递归（四个心智模型）

#### 模型 1：「黑盒假设」（最重要）

★ **假设递归函数已经写好了，它对任何「更小规模」的输入都给正确答案。**

```
写 maxDepth(root) 时：
  ★ 假设 maxDepth(root->left) 已经会算左子树深度
  ★ 假设 maxDepth(root->right) 已经会算右子树深度
  → 你只需要：把这两个结果组合起来
```

★ **不要试图在脑子里展开所有层** —— 那是人做不到的。

#### 模型 2：「每层只做三件事」

```cpp
返回类型 dfs(参数) {
    ① 处理「最小情况」→ 直接返回        // 出口
    ② 把问题拆成「同构的更小问题」→ 递归  // 分
    ③ 把子结果组合成自己的结果 → 返回     // 合
}
```

★ **写代码时，脑子里只有这三步**，不想其他层。

#### 模型 3：「信任链」= 数学归纳法

```
我相信 dfs(更小) 一定对
    ↓
因为 dfs(更小) 也相信 dfs(更更小) 一定对
    ↓
... 一直到 dfs(最小)，它直接返回正确值
    ↓
所以整条链都对
```

★ **基准（出口）正确 + 归纳（组合）正确 = 全部正确。**

#### 模型 4：「参数 = 子问题的定义」

```cpp
dfs(root->left)                  // 参数 = 左子树 → 子问题是「左子树的深度」
dfs(nums, used, path, ans)       // 参数 = 当前状态 → 子问题是「在当前状态下继续选」
```

★ **改参数 = 定义子问题。组合想不出来 → 参数设计有问题。**

### ★ 1.1.3 实际写题的思考流程（四步）

| 步 | 问什么 | 例（104）|
|---|---|---|
| 1 | **函数返回什么？**（一句话）| 以 x 为根的子树的最大深度 |
| 2 | **出口：最小情况返回什么？** | 空节点 → 0 |
| 3 | ★ **dfs(当前) = ??? 用 dfs(子) 表达** | `1 + max(dfs(左), dfs(右))` |
| 4 | **规模递减吗？** | `root->left` 比 `root` 小 ✓ |

★ **第 3 步是关键：想不出来 → 回到第 1 步重新设计参数。**

### ★ 1.1.4 两种形态（先判形态，再写代码）

| | **形态 A：返回结果** | **形态 B：副作用 / 回溯** |
|---|---|---|
| 何时用 | 答案能由子答案**组合** | 要**枚举所有方案** |
| 返回值 | 有（int / bool / 指针）| void |
| 参数 | 通常只有「当前节点/区间」| 还要传「累积状态」（**引用**）|
| 撤销 | ❌ 不用 | ✅ 要 |
| 例 | 二叉树深度（104）、翻转树、求和 | 全排列（46）、子集、岛屿淹掉（200）|

★ **判据（要不要撤销）：这个状态是「最终结果」还是「过程记录」？**
- 最终结果（岛已淹）→ 不撤销
- 过程记录（`path` / `used`）→ 必须撤销

#### ★ 1.1.4.1 两种形态的「三问」不一样（本人实战踩坑）

⚠️ **曾用形态 A 的三问去理解子集（78），完全对不上。**

| 三问 | **形态 A（104 最大深度）** | **形态 B（78 子集）** |
|---|---|---|
| ① dfs 是什么？ | **返回**一个值（最大深度）| **做**一件事（记录当前路径、往后加元素）|
| ② 出口？ | 空节点 → 0 | **不需要**！`for` 循环自然结束就返回 |
| ③ 怎么推进？ | 组合子答案：`1 + max(左, 右)` | **推进状态 + 撤销**：`push_back` → 递归 → `pop_back` |

★ **形态 B 的真正三问：**
```
1. 状态是什么？          → path（已选了哪些）
2. 何时记录答案？        → 每进一层都记（78）/ 只在叶子记（46）
3. 怎么推进 + 怎么撤销？  → push_back → 递归 → pop_back
```

#### ★ 1.1.4.2 本质区别：计算器 vs 枚举生成器

| | 形态 A（104）| 形态 B（78）|
|---|---|---|
| 递归在做什么 | **计算**一个值 | **枚举生成**一组方案 |
| 答案存哪 | **返回值** | **共享状态**（`ans` / `path`）|
| 子问题的含义 | 「左子树多深」 | 「已经选了 path，还能产生哪些方案」|
| 方向 | **自底向上汇总** | **自顶向下探索** |
| 类比 | 打表汇总（分支报数字，我取组合）| 走迷宫记录路径（回头擦痕迹）|

★ **一句话：104 是「问我最远能走多深」，78 是「记录所有走法」。**

#### ⚠️ 1.1.4.3 子集（78）的 `start` 陷阱

```cpp
for (int i = start; i < n; i++) {
    path.push_back(nums[i]);
    dfs(i + 1, ...);      // ★ i + 1，不是 start + 1！
    path.pop_back();
}
```

★ **`start` = 这一层循环的起点；`i` = 这一层当前选中的位置。**
★ **下一层应该从「我选的 i」后面开始 → `i + 1`。**

⚠️ **本人踩坑**：写成 `dfs(start + 1)` → 每层都从同一位置开始 → 产生 `[1,3,3]`、`[2,2]` 这种非法子集。

★ **为什么不用 `used`**：子集「只往后选」→ `i + 1` 天然去重（`[1,2]` 和 `[2,1]` 不会都出现），不需要 `used` 数组。

### ⚠️ 1.1.5 递归的两个风险

| 风险 | 原因 | 对策 |
|---|---|---|
| **爆栈** | 每层调用占栈帧（默认几 MB，深几万层就爆） | 改迭代 + 显式 `stack` |
| **重复计算** | 同一状态被多次访问 → 指数级 | **加 `visited` / 记忆化** |

★ **DFS 题的效率命门 = 有没有正确标记 `visited`。**

### ★ 1.1.6 「递归三问」自测（每次写递归前）

```
1. dfs(参数) 返回什么？（一句话）
2. 出口：最小情况是什么，返回什么？
3. 组合：dfs(当前) = ??? 用 dfs(子) 表达
```
★ **三问都答得出，代码 5 行就写完。**

## 二、DFS（深度优先）

### 2.1 网格 DFS 模板（最常用）

```cpp
void dfs(int i, int j) {
    if (i < 0 || i >= m || j < 0 || j >= n) return;   // ① 越界
    if (grid[i][j] == '0' || visited[i][j]) return;    // ② 已访问 / 不是目标
    
    visited[i][j] = true;                              // ③ 标记（★ 立刻标记）
    
    dfs(i + 1, j);   // 下
    dfs(i - 1, j);   // 上
    dfs(i, j + 1);   // 右
    dfs(i, j - 1);   // 左
}
```

★ **四个方向可以用两个数组简化**：

```cpp
int dx[4] = {1, -1, 0, 0};
int dy[4] = {0, 0, 1, -1};
for (int d = 0; d < 4; d++) dfs(i + dx[d], j + dy[d]);
```

### 2.2 ★ 回溯（Backtracking）= DFS + 撤销

★ **「回溯」不是另一种算法，就是 DFS 加上「用完后撤销」：**

```cpp
void backtrack(路径, 选择列表) {
    if (满足结束条件) { 记录答案; return; }
    for (每个选择) {
        做选择;              // 加入路径
        backtrack(...);      // 递归
        撤销选择;            // ★ 关键：恢复现场
    }
}
```

★ **经典例：全排列**
```cpp
void dfs(int depth) {
    if (depth == n) { ans.push_back(path); return; }
    for (int i = 0; i < n; i++) {
        if (used[i]) continue;
        used[i] = true;
        path.push_back(nums[i]);
        dfs(depth + 1);
        path.pop_back();          // ★ 撤销
        used[i] = false;          // ★ 撤销
    }
}
```

⚠️ **忘记撤销 → 后面的分支被污染 → 答案错。**

## 三、BFS（广度优先）

### 3.1 模板（最短步数）

```cpp
int bfs(起点) {
    queue<状态> q;
    q.push(起点);
    visited[起点] = true;
    int step = 0;
    
    while (!q.empty()) {
        int sz = q.size();              // ★ 当前层的节点数
        for (int k = 0; k < sz; k++) {  // ★ 逐层处理
            auto cur = q.front(); q.pop();
            if (cur == 目标) return step;
            for (相邻状态) {
                if (!visited[相邻]) {
                    visited[相邻] = true;   // ★ 入队时就标记
                    q.push(相邻);
                }
            }
        }
        step++;                         // ★ 一层结束，步数 +1
    }
    return -1;
}
```

### 3.2 ★ 两个关键点

#### ① `visited` 在**入队时**标记（不是出队时）

```
出队时标记 → 同一节点会被多个邻居重复入队 → 队列爆炸
入队时标记 → 每个节点最多入队一次 ✓
```

#### ② 用 `sz = q.size()` 分层

★ **为什么要分层**：这样 `step` 才能准确表示「走了几步」。

```cpp
while (!q.empty()) {
    int sz = q.size();          // 这一层有多少个
    while (sz--) { ... }        // 只处理这一层
    step++;                     // 一层处理完，步数 +1
}
```

### 3.3 BFS 也用于「多源」

★ **多个起点同时入队**（如「腐烂的橘子」）—— 所有源点 `step = 0`，一起扩散。

★ **本质：想象一个「虚拟超级源」，它到所有源点的距离都是 0** → 把「多对一」变成「一对多」。

### ★ 3.4 「扩散 + 累加」是怎么来的（本层最重要的思维）

#### 3.4.1 根源：距离的定义本身就是递推

★ **一切来自 BFS 的一个性质：**
```
BFS 按「距离源点 1 步、2 步、3 步……」的顺序访问
→ 访问顺序的「批次」 = 距离
```

★ **距离的定义：**
```
d(v) = d(u) + 1        （父亲的距离 + 一步）
```
★★ **所以「层数」和「父亲距离 + 1」是同一件事的两种记法。**

```
第 0 层：源点          dist = 0
第 1 层：源点的邻居     dist = 0 + 1 = 1
第 2 层：邻居的邻居     dist = 1 + 1 = 2
```

#### ★ 3.4.2 两种记法（994 vs 542）

| | 994 腐烂橘子 | 542 01 矩阵 |
|---|---|---|
| 距离怎么取 | **批次数** → `level` 变量 | **父节点 + 1** → `dist[子] = dist[父] + 1` |
| 本质 | 「我现在在第几批」| 「我爸离源点多远，我比他远 1」|
| 需要 `sz` 分层吗 | ✅ 需要 | ❌ 不需要 |

★ **994 用 `sz` 是为了省一个数组**（一个变量 vs 一个矩阵），**不是强制**。
★ **542 的距离存在 `dist` 里，每个格子当场确定 → 不用分层。**

#### ★ 3.4.3 为什么能「一次就定死」（关键前提）

★ **BFS 队列的出队顺序 = 距离递增。**

```
→ 当前节点出队时，它的距离已经是最小的了
→ 用它去更新邻居，邻居的距离也一定是最终值
→ 所以「累加一次」就够，不用回头改
```

⚠️ **这个前提的边界：**
- ✅ **边权全部相等** → BFS 成立
- ⚠️ **边权不同**（如某些格子走一步代价 5）→ **BFS 失效 → 要 Dijkstra**

#### ★ 3.4.4 思维上的两个跳跃

**跳跃 1：把「求距离」变成「传播距离」**
```
普通想法：算 A 到 B 的距离 → 从 A 找路到 B
BFS 想法 ：从源点出发，每走一步就把距离【传给邻居】

不是「计算」，而是「传播」—— 像水波 / 病毒传播
```

**跳跃 2：把「多个源」合并成「一个虚拟超级源」**
```
542 有多个 0：
  普通想法：每个 0 跑一次 BFS，取最小值 → O(k · mn)
  多源想法：虚拟超级源到所有 0 距离都是 0 → 一次 BFS → O(mn)
```
★ **本质：把「多对一」反转成「一对多」。**
★ **⚠️ 前提：距离对称（无向图 / 无向网格）。有向图不能反转。**

#### ★ 3.4.5 传播型算法家族（一个骨架长出一族）

★ **所有「传播型」算法都是这个骨架：**

```
1. 初始化：源点代价 = 0，其他 = ∞
2. 循环：从「待处理集」取出一个节点 u
3. 对 u 的每个邻居 v：
       新代价 = 代价(u) + w(u, v)
       如果 新代价 < 代价(v)：
           代价(v) = 新代价          ← ★ 累加 + 更新
           把 v 放进待处理集
4. 直到待处理集为空
```

★ **区别只在「第 2 步怎么取」：**

| 怎么取 | 容器 | 算法 | 边权要求 |
|---|---|---|---|
| 先进先出 | 队列 | **BFS** | 全部相等 |
| 后进先出 | 栈 | DFS | —（非最短路）|
| 优先取 0/1 | `deque` | 0-1 BFS | 只有 0 或 1 |
| **取代价最小** | 小顶堆 | **Dijkstra** | 非负 |
| 反复松弛 N 轮 | — | Bellman-Ford | 可为负 |

★★ **这正好印证「换数据结构 = 换算法」。**

★ **边界：**
- ✅ 边权相等 / 非负 → 可以「一次定死」
- ❌ **边权有负数 → 不能用 BFS/Dijkstra**（后到的可能更优）→ Bellman-Ford / SPFA

## 四、★ DFS vs BFS 怎么选

| 场景 | 选 | 原因 |
|---|---|---|
| **最短步数 / 最少操作** | **BFS** | 按距离扩展，第一次到达即最短 |
| 所有路径 / 方案数 / 能否到达 | **DFS** | 回溯天然枚举 |
| 连通块（岛屿数量） | **DFS 或 BFS 都行** | 只求「有几个块」 |
| 层序遍历 | **BFS** | 天然按层 |
| 深度可能很大（链状） | **BFS** | DFS 会爆栈 |
| 空间敏感（宽而浅） | **DFS** | BFS 队列可能很大 |

★ **口诀：最短找 BFS，方案找 DFS。**

## 五、案例（本人全部独立完成）

### 5.1 岛屿数量（200）—— 网格 DFS + 原地标记

**题目**：`'1'` 陆地、`'0'` 水，求岛屿（上下左右相连）个数。

```cpp
int numIslands(vector<vector<char>>& grid) {
    int m = grid.size(), n = grid[0].size(), count = 0;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (grid[i][j] == '1') { count++; dfs(grid, i, j); }
    return count;
}
void dfs(vector<vector<char>>& g, int i, int j) {
    if (i < 0 || i >= g.size() || j < 0 || j >= g[0].size()) return;
    if (g[i][j] == '0') return;
    g[i][j] = '0';                       // ★ 进入即标记（用原地修改代替 visited）
    dfs(g, i+1, j); dfs(g, i-1, j);
    dfs(g, i, j+1); dfs(g, i, j-1);
}
```

★ **关键技巧：用「改成 `'0'`」代替 `visited` 数组** → 省 O(mn) 空间。
★ **判据：题目允许修改输入吗？允许 → 原地改；不允许 → 用 `visited`。**

### 5.2 腐烂的橘子（994）—— 多源 BFS + 分层 + 计时

**题目**：每分钟腐烂扩散一圈到上下左右，求全部腐烂的分钟数；有幸存者返回 -1。

```cpp
int orangesRotting(vector<vector<int>>& grid) {
    int m = grid.size(), n = grid[0].size();
    queue<pair<int,int>> q;
    int fresh = 0;

    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == 2) q.push({i, j});    // ★ 多源
            else if (grid[i][j] == 1) fresh++;
        }
    if (fresh == 0) return 0;

    int minutes = 0;
    int dx[4] = {1,-1,0,0}, dy[4] = {0,0,1,-1};
    while (!q.empty()) {
        int sz = q.size();                          // ★ 分层
        bool spread = false;
        for (int k = 0; k < sz; k++) {
            auto [i, j] = q.front(); q.pop();n
            for (int d = 0; d < 4; d++) {
                int ni = i+dx[d], nj = j+dy[d];
                if (ni<0||ni>=m||nj<0||nj>=n) continue;
                if (grid[ni][nj] != 1) continue;
                grid[ni][nj] = 2;                   // ★ 入队时改（不是出队时）
                q.push({ni, nj});
                fresh--;
                spread = true;
            }
        }
        if (spread) minutes++;                       // ★ 真的扩散了才 +1
    }
    return fresh == 0 ? minutes : -1;
}
```

★ **四个机制**：多源入队 / `sz` 分层 / `spread` 计时 / `fresh` 计数。
★ **`minutes++` 若不判 `spread` → 会多算 1**（最后一轮只是处理完，没扩散）。

### 5.3 全排列（46）—— 回溯 + `used`

```cpp
vector<vector<int>> permute(vector<int>& nums) {
    vector<vector<int>> ans;
    vector<int> path;
    vector<bool> used(nums.size(), false);
    dfs(nums, used, path, ans);
    return ans;
}
void dfs(vector<int>& nums, vector<bool>& used,
         vector<int>& path, vector<vector<int>>& ans) {   // ★ 全部引用
    if (path.size() == nums.size()) {
        ans.push_back(path);
        return;                                            // ★ 记得 return
    }
    for (int i = 0; i < nums.size(); i++) {
        if (used[i]) continue;
        used[i] = true;  path.push_back(nums[i]);          // ① 做选择
        dfs(nums, used, path, ans);                        // ② 递归
        path.pop_back(); used[i] = false;                  // ③ 撤销
    }
}
```

⚠️ **本人踩坑**：`path` / `ans` 忘了传引用 → 每层拷贝，结果丢。（回溯必须共享同一份状态）

### 5.4 二叉树的最大深度（104）—— 形态 A（返回结果）

```cpp
int maxDepth(TreeNode* root) {
    if (root == nullptr) return 0;                         // 出口
    return 1 + max(maxDepth(root->left),                    // 左
                   maxDepth(root->right));                  // 右
}
```

★ **递归三问**：返回最大深度 / 空节点返回 0 / `1 + max(左,右)`。
★ **不需要引用、不需要撤销** —— 形态 A，每层结果直接 `return`。

### 5.5 子集（78）—— 回溯 + `start`（不用 `used`）

```cpp
vector<vector<int>> subsets(vector<int>& nums) {
    vector<vector<int>> ans;
    vector<int> path;
    dfs(0, nums, path, ans);
    return ans;
}
void dfs(int start, vector<int>& nums,
         vector<int>& path, vector<vector<int>>& ans) {
    ans.push_back(path);                        // ★ 每进一层就记录（不是只在叶子）
    for (int i = start; i < nums.size(); i++) {
        path.push_back(nums[i]);
        dfs(i + 1, nums, path, ans);            // ★ i + 1（不是 start + 1）
        path.pop_back();
    }
}
```

⚠️ **本人踩坑**：写成 `dfs(start + 1)` → 每层从同一位置开始 → 产生 `[1,3,3]`、`[2,2]` 非法子集。

★ **不用 `used`**：`i + 1` 天然去重（只往后选），顺序无关。

### 5.6 二叉树的层序遍历（102）—— 树 BFS

```cpp
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> ans;
    if (root == nullptr) return ans;

    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int sz = q.size();                       // ★ 分层
        vector<int> level;
        for (int k = 0; k < sz; k++) {
            TreeNode* cur = q.front(); q.pop();
            level.push_back(cur->val);
            if (cur->left)  q.push(cur->left);   // ★ 树无环 → 不需要 visited
            if (cur->right) q.push(cur->right);
        }
        ans.push_back(level);                     // ★ 在 for 外（一层一个数组）
    }
    return ans;
}
```

★ **和 994 同构**（分层），区别：邻居变成 `left`/`right`、**不用 `visited`**、每层要收集。

## 六、⚠️ 避坑清单

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | DFS 忘标记 `visited` | **进入就标记**（否则死循环/指数爆炸）|
| 2 | BFS `visited` 在出队时标记 | **入队时标记**（否则重复入队）|
| 3 | BFS 不分层 → `step` 不准 | 用 `sz = q.size()` 分层 |
| 4 | 回溯忘撤销 `used` / `path` | 递归返回后立刻撤销 |
| 5 | 越界判断写在标记之后 | **先判越界**再访问 |
| 6 | 深递归爆栈 | 改迭代 + 显式栈 |
| 7 | 求最短却用 DFS | 改用 BFS |
| 8 | 网格方向数组写错 | `dx/dy` 成对检查 |
| 9 | **回溯的 `path`/`ans` 按值传递** | 必须传引用 `&`（要共享同一份状态）—— 本人踩坑（46）|
| 10 | **回溯终止后忘 `return`** | 满了就 `return`（否则空转）|
| 11 | **子集传 `start+1`** | 应为 **`i+1`**（本人踩坑，78）|
| 12 | 子集只在叶子记录 | **每进一层就 `ans.push_back`**（每个节点都是子集）|

| 14 | `ans.push_back(level)` 写在 for 里 | 写在 **for 外**（一层一个数组）—— 102 |
| 15 | 994 的 `minutes++` 不判断 | 只在该层**真的扩散**时 +1（`spread`），否则多算 1 |

## 七、一句话总结

> ★ **DFS = 一条路走到黑（递归/栈）；BFS = 一层层扩散（队列）。**
>
> ★ **判据：最短步数 → BFS；方案/路径/连通 → DFS。**
>
> ★ **两个命门：DFS 的 `visited` 要「进入即标记」；BFS 的 `visited` 要「入队即标记」，并用 `sz` 分层。**
>
> ★ **回溯 = DFS + 撤销现场（`push_back` 配 `pop_back`）。**
>
> ★ **递归两种形态：A 返回结果（104）/ B 副作用+回溯（46、78）。**
> ★ **回溯铁律：`path`/`ans` 传引用；终止要 `return`；子集传 `i+1`。**

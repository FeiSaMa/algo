## A. 哈希表

### A1
**Q：前缀和 + 哈希的题，`mp` 初始化第一行写什么？为什么？**
A：`mp[0] = 1;` —— 登记「空区间」：前缀和 0 出现过 1 次；漏了会丢掉所有「从下标 0 开始」的子数组。

### A2
**Q：`insert().second` 能一次完成「查 + 记」，前提是什么？**
A：**查的键 == 插的键**。（存在重复元素 ✅；两数之和 ❌ 因为查 `target-x`、插 `x`）

### A3
**Q：想判断 `unordered_map` 里某个键在不在，**不该**用什么？为什么？**
A：不该用 `mp[k]` —— 键不存在时它会**自动创建 0**，改变容器状态。

### A4
**Q：`unordered_map` 的 `insert` 遇到**已存在的键**会怎样？**
A：**不覆盖**，保留旧值，返回 `ok = false`。要覆盖必须用 `mp[k] = v`。

### A5
**Q：一 key 对应多个结果时，值该用什么类型？**
A：`map<K, vector<V>>`，配合 `mp[key].push_back(x)`（自动创建，不需 if）。

### A6
**Q：数组能不能直接当 `unordered_map` 的键？**
A：不能 —— 数组名退化成指针，比较的是地址。要先**编码**（拼成 string，如计数用 `*` 分隔）。

## B. 前缀和 / 差分

### B1
**Q：前缀和数组为什么开 `n+1`？**
A：留 `pre[0] = 0` 表示空区间和 → 让 `pre[r+1] - pre[l]` 在 `l=0` 时不用特判。

### B2
**Q：差分数组为什么开 `n+1`？**
A：**防越界** —— 当 `r = n-1` 时 `d[r+1] = d[n]` 需要这一格（虽然它不参与还原）。

### B3
**Q：区间 `[l, r]` 全体 +v，差分改哪两格？**
A：`d[l] += v;  d[r+1] -= v;`

### B4
**Q：闭区间 `[l, r]` 的和用前缀和怎么算？**
A：`pre[r+1] - pre[l]`

### B5
**Q：题目编号 1-based（如航班 1..n），差分改哪两格？**
A：`d[first-1] += v;  d[last] -= v;` —— **起点减 1，终点不减**。

### B6
**Q：二维前缀和的查询公式（容斥）？**
A：`pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1]`

## C. 二分

### C1
**Q：二分为什么用 `mid = left + (right-left)/2` 而不是 `(left+right)/2`？**
A：防溢出 —— `left + right` 可能超出 int 范围。

### C2
**Q：`mid` 向下取整时，哪个赋值安全？**
A：只有 **`right = mid`** 安全；`left = mid` 会死循环（因为 `mid` 可能 == `left`）。

### C3
**Q：二分 `lower_bound` 和 `upper_bound` 只差什么？**
A：一个符号 —— `nums[mid] >= target` vs `nums[mid] > target`。

### C4
**Q：二分找到位置后，怎么判 target 到底存不存在？**
A：`pos == n || nums[pos] != target`

### C5
**Q：二分答案里，`can(mid)` 为真时该写 `right = mid` 还是 `mid - 1`？**
A：**`right = mid`** —— mid 可行可能就是答案，别排除它。

## D. 双指针

### D1
**Q：对撞双指针里，盛最多水的容器为什么移动「较矮」的那根？**
A：宽度只会减小 → 移高的 `min` 不变或更小、宽度还减 → 面积只会变小；移矮的 `min` 可能变大。

### D2
**Q：三数之和去重，找到解之后 `left` 和 `right` 各自怎么跳？**
A：`while (nums[left] == nums[left+1]) left++;` / `while (nums[right] == nums[right-1]) right--;` （**自己比自己旁边，自己走**）

### D3
**Q：双指针判重时，`left < right` 为什么要放 `&&` 左边？**
A：短路求值 —— 防越界。

### D4
**Q：快慢指针（数组版）的万能骨架是什么？**
A：`int slow=0; for(fast){ if(保留条件){写nums[slow]; slow++;} } return slow;`

### D5
**Q：最长连续序列能 O(n) 的关键判断是什么？**
A：`if (st.count(x-1)) continue;` —— **只从链头数**（没有前驱的才是链头），否则 O(n²)。

## D'. 滑动窗口（求最短型 · 76 的五个坑）

### W1
**Q：求【最短】的滑窗（如最小覆盖子串），答案在什么时候记录？**
A：**在 `while` 收缩【之前】记录** —— 那时窗口还合法；缩完就不满足了。（求最短：缩前记）

### W2
**Q：滑窗收缩时，减计数和 `left++` 的**顺序**？**
A：**先 `cnt[s[left]]--;`，再 `left++;`** —— 反了就会减错字符。

### W3
**Q：「窗口覆盖 t」的判据是 `!=` 还是 `<`？**
A：**`<`** —— 窗口计数 `>=` t 的计数就够（**可以多**），不是必须相等。

### W4
**Q：写 `isMatched(int* a, int* b, int n)` 时最易犯的下标错误？**
A：写成 `b[2]` —— 应为 **`b[i]`**（下标跟循环变量）。

### W5
**Q：`int cnt[128];` 直接 `cnt[c]++` 会怎样？**
A：**垃圾值**！（内置数组不自动初始化）→ 必须 `int cnt[128] = {0};` 或 `{}`。

### W6
**Q：求【最长】的滑窗（如 1004），答案什么时候记录？**
A：窗口**合法时**记录（也是收缩前）。★ 共同点：**只在窗口满足条件时记答案**。

### W7
**Q：滑窗收缩循环（求解法本身）的`while`条件怎么写？**
A：`while (窗口满足条件) { 记录答案; 收缩; }` —— **不是** `while (!满足)`。写反就变成「越缩越不满足」。

## E. 排序 / 贪心

### E1
**Q：区间题里，「选最多 / 腾空间」按哪个端点排？**
A：**右端点**（结束早的给后面留空间）。

### E2
**Q：区间题里，「合并 / 连成链」按哪个端点排？**
A：**左端点**（按起点才能顺序缝合）。

### E3
**Q：`[1,4]` 和 `[4,5]` 端点相接，无重叠区间题算不算重叠？**
A：**不算** → 用 `itv[0] >= lastEnd` 判「不重叠」。

### E4
**Q：同样端点相接，合并区间题算不算重叠？**
A：**算** → 用 `itv[0] <= ans.back()[1]` 判「重叠」。

### E5
**Q：`sort` 比较器能不能写 `return a <= b;`？**
A：不能 —— 违反严格弱序（`comp(a,a)` 必须为 false），会 UB。

### E6
**Q：`vector<vector<int>>` / `pair` 默认按什么排？**
A：**字典序**（先比 `[0]`，再比 `[1]`）—— 所以想按右端点排必须自己写比较器。

### E7
**Q：合并区间时，`ans.back()[1] = itv[1]` 有什么问题？**
A：遇到被包含的区间（如 `[1,10]` 后接 `[2,3]`）会把 end 缩小 → 必须 `max(ans.back()[1], itv[1])`。

## F. STL / 容器

### F1
**Q：一行给 `unordered_set` 去重的写法？**
A：`unordered_set<int> st(nums.begin(), nums.end());`

### F2
**Q：`max_element(b, e)` 返回什么？怎么取最大值？**
A：返回**迭代器**；用 `*max_element(...)` 解引用取值。

### F3
**Q：`stack::pop()` 返回被弹出的值吗？**
A：**不返回**。要 `int x = st.top(); st.pop();`

### F4
**Q：`stack` 有 `clear()` 吗？能遍历吗？**
A：都没有。清空只能 `while (!st.empty()) st.pop();`

### F5
**Q：`for (auto& [k, v] : mp)` 里 `&` 的作用？**
A：引用 —— 避免拷贝整个 value（value 是 vector 时尤其重要）。

### F6
**Q：链表题为什么要用 dummy 哑节点？**
A：避免「头节点特殊处理」—— 所有节点走同一条路径。返回 `dummy.next`。

## G. 高频坑（自己踩过的）

### G1
**Q：`size_t` 做下标，`right = nums.size() - 1` 在空数组时会怎样？**
A：无符号回绕成巨大值。→ 用 `int` 下标 + `(int)nums.size()`。

### G2
**Q：哈希表循环里「先记后查」会怎样？**
A：读到刚插入的自己 → 两数之和会返回 `{0,0}`。

### G3
**Q：贪心分段（送货/分割数组）里，切新段时累加器怎么处理？**
A：`cur = 当前元素` —— **不是清零**，也不是保留。

### G4
**Q：`while` 循环里最常见的一类死循环是什么？**
A：**找到答案却不推进指针**（三数之和）/ `left = mid`。判据：每个分支都要让状态前进。

### G5
**Q：`int` 存前缀和 / 累加会有什么问题？**
A：溢出 → 一律 `long long`。

### G6
**Q：整数平方能不能用 `pow(x, 2)`？**
A：不建议 —— `pow` 是浮点函数，慢且可能有精度问题。用 `x * x`。

## H. DFS / BFS

### H1
**Q：BFS / DFS 的本质区别是什么？（一句话）**
A：**同一个遍历框架，取策略不同** —— 取「最早入的」（队列）是 BFS，取「最晚入的」（栈）是 DFS。

### H2
**Q：为什么「层序」差异来自容器？（关键瞬间）**
A：处理完某节点后，待处理集里**同时有上层和本层**：队列让「早入队的上层节点」先出 → 层序不乱；栈让「晚入栈的下层节点」先出 → 直接钻下去。

### H3
**Q：求最短步数为什么必须 BFS？**
A：BFS 按「距离」顺序出队 → **第一次到达目标 = 步数最少**。DFS 先到的不一定最短。

### H4
**Q：DFS 的 `visited` 什么时候标记？BFS 呢？**
A：DFS **进入时**标记；BFS **入队时**标记（否则同一节点会被多个邻居重复入队）。

### H5
**Q：BFS 怎么按层计步数（`step`）？**
A：用 `int sz = q.size();` 只处理这一层的 `sz` 个，然后 `step++`。

### H6
**Q：多源 BFS（如腐烂的橘子）怎么开始？**
A：**把所有源点一次性全部入队**（都算第 0 层），然后一起扩散。

### H7
**Q：BFS 里 `step` 容易多算 1，怎么避免？**
A：只在该层**真的扩散出新节点**时才 `step++`（用 `spread` 标记），或从 `step = -1` 起步。

### H8
**Q：什么情况下 DFS 和 BFS 都可以？**
A：只问「连通块个数 / 能否到达」时都行（如岛屿数量）；只有问「最短」才必须 BFS。

### H9
**Q：换数据结构 = 换算法 —— 举例？**
A：队列 → BFS；栈 → DFS；`deque`（0/1 边）→ 0-1 BFS；小顶堆 → Dijkstra；堆 + 估价 → A*。

## I. 递归 / 回溯

### I1
**Q：什么时候该选递归？（三个判据）**
A：① 问题呈树形/自相似；② 答案能由**子答案组合**出来；③ 有明确的**最小子问题（出口）**。

### I2
**Q：写递归时最重要的心智模型是什么？**
A：**黑盒假设** —— 假设 `dfs(更小)` 已经正确，只负责「组合」它。不要试图在脑子里展开所有层。

### I3
**Q：递归正确性靠什么保证？**
A：**数学归纳法** —— 基准（出口）正确 + 归纳（组合）正确 = 全部正确。

### I4
**Q：「递归三问」是什么？**
A：① dfs(参数) 返回什么？② 出口返回什么？③ `dfs(当前) = ???` 用 dfs(子) 表达？

### I5
**Q：组合关系想不出来，说明什么？**
A：**参数设计有问题**（参数 = 子问题的定义，改参数重新定义子问题）。

### I6
**Q：递归的两种形态？怎么判？**
A：**形态 A 返回结果**（答案能组合，如 104 深度）；**形态 B 副作用/回溯**（枚举所有方案，如 46 全排列）。判据：要「枚举所有」→ B。

### I7
**Q：回溯时哪些参数必须传引用？**
A：**会被修改的累积状态**（`path` / `ans` / `used`）必须 `&`；只读输入用 `const&`；简单类型（int/bool）可值传。★ 判据：dfs 里要改它吗？

### I8
**Q：什么时候「要撤销」，什么时候「不用撤销」？**
A：判据 —— 这个状态是「最终结果」还是「过程记录」？<br>最终结果（岛已淹）→ 不撤销；过程记录（`path`/`used`）→ 必须撤销。

### I9
**Q：形态 A（104 深度）和形态 B（78 子集）的「三问」有什么不同？**
A：A 问「返回什么/出口/怎么组合」；B 问「**状态是什么** / **何时记录答案** / **怎么推进+撤销**」。B **不需要出口**（for 自然结束）。

### I10
**Q：子集（78）为什么递归传 `i + 1` 而不是 `start + 1`？**
A：`start` 是这层循环起点，`i` 是这层实际选中的位置。下一层要从「我选的 i」后面开始。★ 传 `start+1` 会产生 `[1,3,3]`、`[2,2]` 等非法子集。

### I11
**Q：子集为什么不用 `used` 数组，而全排列必须用？**
A：子集「只往后选」（`i+1` 天然去重），顺序无关；全排列「任意位置选」，顺序有关 → 必须用 `used` 记录谁被用了。

### I12
**Q：一句话区分形态 A 和形态 B 的本质？**
A：A 是**计算器**（算出一个值，答案在返回值里）；B 是**枚举生成器**（生成一组方案，答案在共享状态里）。

### H10
**Q：「扩散 + 累加」为什么能成立？根源是什么？**
A：**距离的定义就是递推** —— `d(v) = d(u) + 1`（父亲距离 + 一步）。BFS 的「层数」和「父距离 + 1」是同一件事的两种记法。

### H11
**Q：为什么 BFS 能「一次就定死」距离，不回头改？**
A：因为 **BFS 出队顺序 = 距离递增** → 节点出队时距离已是最小 → 用它更新邻居，邻居也是最终值。

### H12
**Q：什么时候「一次定死」会失效？**
A：**边权不相等**时（如走一步代价 5）→ BFS 失效 → 要 Dijkstra（优先队列取代价最小）。边权有负数 → Bellman-Ford。

### H13
**Q：多源 BFS 的本质是什么？**
A：想象一个**虚拟超级源**，它到所有源点距离都是 0 → 把「多对一」反转成「一对多」，复杂度从 O(k·mn) 降到 O(mn)。⚠️ 前提：距离对称（无向）。

### H14
**Q：994（腐烂橘子）和 542（01矩阵）的分层区别？**
A：994 要**全局时间** → 用 `sz` 分层 + `level`；542 要**每个格子的距离** → `dist[子] = dist[父] + 1`，**不需要分层**。

### H15
**Q：换数据结构 = 换算法，传播型算法家族举例？**
A：队列→BFS（边权相等）；deque→0-1 BFS（边权 0/1）；小顶堆→Dijkstra（非负）；反复松弛→Bellman-Ford（可负）。

### H16
**Q：「改一个变量的值」什么时候算「语义混乱」？**
A：当这个值在题目语义里**已有别的含义**时。例：542 的 `0` 本义是「源点/距离0」，拿来标「已访问」→ 冲突。（994 把 1→2 是语义一致的，因为「腐烂」就是题目概念）

## J. 图

### J1
**Q：建图的本质是什么？**
A：把「一堆关系数据」变成「按节点索引的邻接关系」—— 把「O(m) 查邻居」变成「O(1) 查邻居」。

### J2
**Q：边方向的判据？**
A：读成「**从 X 能到 Y**」，边就是 X→Y。例：`[a,b]` 表示修 a 前修 b → 边 `b → a`。

### J3
**Q：邻接矩阵的 `g[u][j]` 和邻接表的 `g[u]` 有什么区别？**
A：矩阵的 `g[u][j]` 是 **0/1 标记**（是否相连）；表的 `g[u]` 是**邻居节点列表**。遍历矩阵要 `if (g[u][j]==1 && !visited[j]) dfs(j)`。

### J4
**Q：图为什么必须有 `visited`，树不用？**
A：图可能有环 → 不加会无限递归爆栈；树无环。

### J5
**Q：拓扑排序（Kahn）的核心步骤？**
A：① 建图 + 统计入度 ② 入度为 0 的入队 ③ 出队时 `--indegree[邻居]`，归零则入队 ④ `done == n` 判无环。

### J6
**Q：入度是什么？只有 0/1 吗？**
A：**入度 = 指向该节点的边数 = 「还有几个前置没完成」**。可以是 0、1、2、3……（看有多少前置）。

### J7
**Q：有环时拓扑排序为什么卡住？**
A：环上每个节点都被环内其他节点指着 → 入度永远降不到 0 → 队列搞空也处理不完。

### J8
**Q：127 单词接龙的模式匹配怎么做？**
A：把每个词拆成 L 个模式（`hot` → `*ot`/`h*t`/`ho*`），建 `模式 → 词列表`；BFS 时 O(L) 生成模式直接查邻居。复杂度 O(n²L) → O(n·L²)。

### J9
**Q：模式匹配里 `visited` 和 `clear()` 各防什么？**
A：`visited` 防「同一词被多个路径发现」（**必需**）；`clear()` 防「同一模式被多次扫描」（**仅优化**）。★ 缺 visited → 队列爆炸 MLE。

### J10
**Q：`clear()` 为什么不影响正确性？**
A：因为清空发生在「已遍历完该模式全部元素」之后 —— 那些词已经入队/已访问，删掉「走过的边」不影响可达性。

### J11
**Q：怎么识别「这题要用图」？（三个自问）**
A：① 题里有「相连/依赖/能到/相邻/分组」？② A 通过中间步骤能影响 B？（关系可传递）③ 能把「局面」编码成状态、「操作」编码成转移？

### J12
**Q：什么时候不是图？**
A：「连续子数组」类（位置线性、无分叉）、「排序后处理」类（全序）。★ 判据：关系是「线性的」还是「网状的」？线性→扫描，网状→图。

### J13
**Q：隐式图的判据？**
A：能把「局面」编码成状态、「一步操作」写成「状态→新状态」→ 隐式图（如单词接龙、转盘锁、倒水问题）→ BFS 求最短。

### J14
**Q：图问题的「问什么 → 用什么」对照？**
A：连通块/分组→DFS·BFS·并查集；能否到达→DFS/BFS；最短步数→BFS；有环/能否全完成→拓扑排序；两点同组（动态合并）→并查集。

## K. 动态规划

### K1
**Q：DP 三要素是什么？**
A：**状态**（`dp[i]` 表示什么）/ **转移**（`dp[i]` 怎么由更小的推出来）/ **边界**（最小子问题的答案）。对应递归三问。

### K2
**Q：怎么找 DP 状态？（三步）**
A：① 答案的目标量是什么 ② 把「固定目标」变成变量 `i` ③ 验证：问「最后一步」，能推出转移就对了。

### K3
**Q：★ 状态设计的分水岭：「前 i 个」vs「以 i 结尾」？**
A：**禁止型约束**（不能相邻）→ 前 i 个，答案 `dp[n]`；**连续型约束**（必须相连）→ 以 i 结尾，答案 `max(dp)`。

### K4
**Q：「前 i 个最优」用在连续问题上会怎样？**
A：丢失「结束位置」→ 无法判断能否接上 `nums[i]` → 转移写不出来（见 53）。

### K5
**Q：★ 0-1 背包和完全背包的唯一区别？**
A：**内层循环方向** —— 0-1 **倒序**（每物品最多一次）；完全背包**正序**（可无限用）。

### K6
**Q：★ 为什么 0-1 背包必须倒序？**
A：倒序保证 `dp[j-x]`（下标更小）还没被本轮修改 → 读到的是「上一轮」的值。正序会读到刚改的 → 等于重复使用。

### K7
**Q：打家劫舍偷了第 i 间，为什么用 `dp[i-2]`？**
A：偷了 i 就禁 i-1，能自由选的范围正好是「前 i-2 间」。

### K8
**Q：最大子数组和 / LIS 的答案为什么是 `max(所有 dp)` 而不是 `dp[n-1]`？**
A：状态是「以 i 结尾」→ 最优的那条不一定结束在最后。

### K9
**Q：LCS 的转移方程？**
A：`text1[i-1]==text2[j-1]` → `dp[i-1][j-1]+1`（配对消耗）；不等 → `max(dp[i-1][j], dp[i][j-1])`（抛弃一个）。

### K10
**Q：二维 DP（LCS）的答案在哪？**
A：**右下角 `dp[m][n]`**（注意和一维「以 i 结尾」不同）。

### K11
**Q：DP 用什么条件判断能不能用？**
A：① 最优子结构 ② 重叠子问题 ③ 无后效性。

### K12
**Q：DP 的两种写法？**
A：递推（自底向上，无递归开销）/ 记忆化搜索（自顶向下，递归 + memo）。★ 建议先用记忆化。

## 〇、一句话总纲

★ **链表 = 用指针串起来的节点，每个节点存「值 + 下一个节点的地址」。**

```cpp
struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};
```

★ **和数组对比**：

| | 数组（vector）| 链表 |
|---|---|---|
| 内存 | **连续** | 分散（每个节点单独分配）|
| 随机访问 `v[i]` | ✅ O(1) | ❌ O(n)（必须一路走）|
| 中间插入/删除 | O(n)（要搬移）| ✅ O(1)（改指针）|
| 缓存友好 | ✅ 很好 | ❌ 差（跳来跳去）|
| 末尾追加 | 均摊 O(1) | O(1)（如果有 tail 指针）|

★ **实际做题的结论：链表题难在「指针操作」，不难在「算法」。**

## 一、② 个必知基础操作

### 1.1 遍历

```cpp
for (ListNode* p = head; p != nullptr; p = p->next) {
    // 用 p->val
}
```

⚠️ **终止条件必须是 `p != nullptr`**（不是 `p->next != nullptr`，除非你要看最后一个的下一个）。

### 1.2 ★ dummy 哑节点（最重要技巧）

```cpp
ListNode dummy;              // ★ 栈上创建（推荐）
ListNode* cur = &dummy;      // cur 指向「结果链表的尾部」

// ... 往 cur->next 接节点，然后 cur = cur->next

return dummy.next;           // ★ 返回 dummy 的下一个（真正的头）
```

★ **为什么用 dummy**：
- **避免「头节点特殊处理」** —— 不用判断「结果链表还是空的」
- **所有节点走同一条代码路径** → 代码简洁、不易错

★ **注意事项**：
- `ListNode dummy;` **在栈上**（不要 `new`）→ 函数返回时自动销毁，但我们返回的是 `dummy.next`（堆上的真实节点）→ **安全**
- ⚠️ **不要返回 `&dummy`**（栈变量，出函数就失效）

### 1.3 创建节点

```cpp
ListNode* node = new ListNode(val);      // 堆上分配
tail->next = node;
tail = tail->next;
```

⚠️ **LeetCode 题里不用 `delete`**（评测系统管理），但**真实工程要管内存**。

## 二、已做题目

### 2.1 合并两个有序链表（21）★ dummy 的经典应用

```cpp
ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
    ListNode dummy;                     // ★ 哑节点
    ListNode* cur = &dummy;
    while (list1 != nullptr && list2 != nullptr) {
        if (list1->val <= list2->val) {
            cur->next = list1;
            list1 = list1->next;
        } else {
            cur->next = list2;
            list2 = list2->next;
        }
        cur = cur->next;
    }
    cur->next = (list1 != nullptr) ? list1 : list2;   // ★ 剩下的直接接上
    return dummy.next;
}
```

★ **关键点**：
- **`<=`** 保证「稳定」（相等时取 list1 的，保持相对顺序）
- 循环结束后，**剩下的那条链表整体接上**（不用再逐个搬）
- 返回 **`dummy.next`**

### 2.2 两数相加（2）★ 进位 + 长度不等

```cpp
ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
    int sum = l1->val + l2->val;
    bool flag = false;                  // 进位
    ListNode* ans;
    if (sum < 10) {
        ans = new ListNode(sum);
        l1 = l1->next; l2 = l2->next;
    } else {
        ans = new ListNode(sum - 10);
        l1 = l1->next; l2 = l2->next;
        flag = true;
    }
    ListNode* tail = ans;

    while (l1 != nullptr || l2 != nullptr || flag) {   // ★ 注意 flag
        int a = (l1 != nullptr) ? l1->val : 0;
        int b = (l2 != nullptr) ? l2->val : 0;
        sum = a + b + (flag ? 1 : 0);
        if (sum < 10) { tail->next = new ListNode(sum); flag = false; }
        else          { tail->next = new ListNode(sum - 10); flag = true; }
        tail = tail->next;
        if (l1 != nullptr) l1 = l1->next;
        if (l2 != nullptr) l2 = l2->next;
    }
    return ans;
}
```

★ **关键点**：
- **`|| flag`** 是循环条件的一部分 —— 最后可能还有进位（如 `[5] + [5] = [0,1]`）
- **`(l1 != nullptr) ? l1->val : 0`** —— 两条链长度不等时补 0
- ★ **本题没用 dummy**（第一节点特殊处理）→ ⚠️ 这正是 dummy 能避免的麻烦

★ **用 dummy 可以更简洁**（改进版）：

```cpp
ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
    ListNode dummy;
    ListNode* cur = &dummy;
    int carry = 0;
    while (l1 || l2 || carry) {
        int a = l1 ? l1->val : 0;
        int b = l2 ? l2->val : 0;
        int sum = a + b + carry;
        cur->next = new ListNode(sum % 10);     // ★ 取个位
        carry = sum / 10;                        // ★ 进位
        cur = cur->next;
        if (l1) l1 = l1->next;
        if (l2) l2 = l2->next;
    }
    return dummy.next;
}
```

★ **`sum % 10` / `sum / 10`** 比 `if (sum < 10) ... else ...` 干净得多。

## 四、⚠️ 避坑清单

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | 遍历条件写 `p->next != nullptr` | 一般写 **`p != nullptr`** |
| 2 | **访问 `p->val` 前没判空** | `if (p != nullptr) ...` 或 `p ? p->val : 0` |
| 3 | **返回 `&dummy`** | 返回 **`dummy.next`**（dummy 是栈变量）|
| 4 | 两数相加漏最后的进位 | 循环条件加 **`\|\| carry`** |
| 5 | 两条链长度不等没补 0 | `l1 ? l1->val : 0` |
| 6 | 合并后剩下的一段忘了接 | `cur->next = list1 ? list1 : list2;` |
| 7 | 移动指针顺序错（`cur = cur->next` 放错位置）| **先接节点，再移 cur** |
| 8 | `ListNode dummy = new ListNode();` | ❌ `new` 返回指针；用 `ListNode dummy;` 或 `ListNode* dummy = new ListNode();` |

- 判环：`fast` 走 2 步、`slow` 走 1 步 → 有环必相遇
- 找中点：`fast` 到末尾时，`slow` 正好在中间

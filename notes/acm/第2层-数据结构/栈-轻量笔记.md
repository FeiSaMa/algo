## 〇、一句话总纲

★ **栈 = 后进先出（LIFO, Last In First Out）。**

```
push → │ c │
       │ b │
       │ a │  ← top（只能从这里进出）
       └───┘
```

★ **栈只暴露三个操作**：`push`（压）、`pop`（弹）、`top`（看顶）。

★ **判据：题目有「最近的、还没配对的」这种需求 → 栈。**

```
括号匹配      → 最近的未配对左括号
撤销操作      → 最近的操作
表达式求值    → 最近的运算符
单调栈        → 最近的大于/小于当前元素
```

## 一、C++ 的 `stack` 基本用法

```cpp
#include <stack>
stack<int> st;

st.push(x);        // 压栈
st.pop();          // 弹栈（★ 无返回值！只弹出）
st.top();          // 看栈顶（★ 不弹出）
st.empty();        // 是否为空
st.size();         // 元素个数
```

### ⚠️ 三个必须知道的坑

| # | 坑 | 说明 |
|---|---|---|
| 1 | **`pop()` 不返回值** | `int x = st.pop();` ❌ 编译错误。要 `int x = st.top(); st.pop();` |
| 2 | **`top()` / `pop()` 前必须 `!empty()`** | 空栈访问 = **UB**（不报错，直接崩）|
| 3 | **`stack` 没有 `clear()`、不能遍历** | 要清空只能 `while (!st.empty()) st.pop();` |

★ **`stack` 是「适配器」** —— 默认底层是 `deque`，只露出受限接口（故意限制，防误用）。

## 二、已做题目

### 2.1 有效的括号（20）★ 栈的教科书题

★ **要求**：判断 `(){}[]` 是否合法配对。

```cpp
bool isValid(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);                          // 左括号 → 压栈
        } else {
            if (st.empty()) return false;        // ★ 右括号但栈空 → 不合法
            char top = st.top();
            st.pop();
            if ((c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{')) {
                return false;                     // ★ 类型不匹配
            }
        }
    }
    return st.empty();                            // ★ 最后必须栈空
}
```

★ **三个关键判断**：
1. **右括号来时栈空** → 不合法（如 `")"`）
2. **类型不匹配** → 不合法（如 `"(]"`）
3. **遍历完栈没空** → 不合法（如 `"("`）

★ **简化写法**（用 map 存配对关系）：

```cpp
bool isValid(string s) {
    stack<char> st;
    unordered_map<char,char> match = {{')','('}, {']','['}, {'}','{'}};
    for (char c : s) {
        if (match.count(c)) {                     // 是右括号
            if (st.empty() || st.top() != match[c]) return false;
            st.pop();
        } else st.push(c);
    }
    return st.empty();
}
```

★ **`match.count(c)` 判「是不是右括号」** —— 比三个 `||` 简洁（**这就是哈希表的用处**）。

### 2.2 最小栈（155）★ 辅助栈

★ **要求**：设计栈，支持 `push`/`pop`/`top`/`getMin`，全部 **O(1)**。

★ **核心思想：用一个辅助栈记录「每一步的最小值」。**

```cpp
class MinStack {
private:
    stack<int> st;         // 主栈：所有元素
    stack<int> minst;      // 辅助栈：历史最小值（单调不增）
public:
    void push(int value) {
        st.push(value);
        if (minst.empty() || value <= minst.top())    // ★ <=
            minst.push(value);
    }
    void pop() {
        if (st.top() == minst.top()) minst.pop();     // ★ 弹的是最小值才同步弹
        st.pop();                                     // ★ 先判断，再 pop
    }
    int top()    { return st.top(); }
    int getMin() { return minst.top(); }
};
```

★ **两个关键**：
1. **`value <= minst.top()` 用 `<=`** —— 相等值也要压，否则 `pop` 时会弹空
2. **`pop` 里先比较再 `st.pop()`** —— 因为 `st.top()` 在 pop 之后就不存在了

★ **另一种写法**（每次都压当前最小值，空间换简单）：

```cpp
void push(int val) {
    st.push(val);
    minst.push(minst.empty() ? val : min(minst.top(), val));   // ★ 每步都记录
}
void pop() { st.pop(); minst.pop(); }    // ★ 两个一起弹，不用判断
```

★ **对比**：

| | 只在更小时压（本人写法）| 每次都压 |
|---|---|---|
| 空间 | 小 | 大（= 主栈大小）|
| `pop` 逻辑 | 要判断 | 直接弹两个 |

## 四、⚠️ 避坑清单

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | `int x = st.pop();` | `int x = st.top(); st.pop();` |
| 2 | 空栈调 `top()` / `pop()` | 先 `!st.empty()` |
| 3 | 想 `clear()` | `while (!st.empty()) st.pop();` |
| 4 | 想遍历栈 | 栈不能遍历 → 换 `vector` 或复制一份 |
| 5 | 括号题最后忘了判栈空 | `return st.empty();` |
| 6 | 最小栈用 `>` 而不是 `<=` | 相等值会弹空 |
| 7 | 最小栈 `pop` 里先 `st.pop()` 再比较 | 先比较 `st.top()`，再弹 |

## 六、一句话总结

> ★ **栈 = 后进先出；只暴露 `push` / `pop` / `top`。**
>
> ★ **判据：需要「最近的、还没配对的」→ 栈。**
>
> ★ **`pop()` 无返回值；`top()`/`pop()` 前必判空；没有 `clear()` 不能遍历。**
>
> ★ **两大套路：**
> 1. **括号匹配**（20）：左括号压栈，右括号比对弹栈，最后栈必空
> 2. **辅助栈记历史最值**（155）：`minst` 同步压最小值，`pop` 时同步弹
>
> ★ **进阶 = 单调栈**（找下一个更大/更小），另见专题笔记。

## 〇、一句话总纲

★ **图 = 节点 + 边。遍历方式就是 DFS/BFS，只是「邻居」从「四方向」变成「邻接表」。**

```
网格（200 岛屿）：邻居 = 上下左右 4 个格子
图（一般）：      邻居 = 邻接表里列出的节点
```

★ **所以你已经会遍历图了** —— 只是换一种「取邻居」的方式。

## 〇·补、★ 怎么识别「这题要用图」

### ★ 三个自问（任一为「是」→ 考虑图）

```
① 题里有「相连 / 依赖 / 能到 / 相邻 / 分组」这类词？
② A 通过一系列中间步骤能影响/到达 B？（关系可传递）
③ 能不能把「局面」编码成状态，「操作」编码成状态转移？
```

### ★ 第一层：信号词

| 题目用语 | 图论含义 |
|---|---|
| 相连 / 连接 / 连通 | 边 |
| 前置 / 依赖 / 必须先 | **有向边** |
| 从 A 能到 B / A 能变成 B | 有向边 |
| 相邻 / 周边 / 上下左右 | 边（网格）|
| 网络 / 路线 / 航班 / 管道 | 边 |
| 分组 / 合并 / 同一个集合 | 连通分量 |

### ★ 第二层：关系可传递（更深）

★ **图论处理的是「关系链」：**
```
A 和 B 有关系，B 和 C 有关系 → 问：A 和 C 有没有关系？
```

| 题 | 传递关系 |
|---|---|
| 547 省份 | 0-1 相连，1-2 相连 → 0 和 2 同省 |
| 841 钥匙 | 0 有 1 的钥匙，1 有 2 的 → 能进 2 |
| 207 课程表 | 修 2 要修 1，修 1 要修 0 → 2 依赖 0 |
| 127 单词接龙 | hit→hot→dot→dog → hit 能到 dog |

### ★ 第三层：状态空间可枚举（隐式图的判据）

★ **把「局面」写成状态，「一步操作」写成转移。**

| 题 | 状态 | 操作 |
|---|---|---|
| 127 单词接龙 | 当前单词 | 改一个字母 |
| 542 01 矩阵 | 当前格子 | 走一格 |
| 994 腐烂橘子 | 当前腐烂集合 | 每分钟扩散 |
| 752 打开转盘锁 | 4 位数字 | 转一格 |
| 773 滑动谜题 | 3×3 排列 | 移动空格 |
| 倒水问题 | (a, b) 水量 | 倒水 |

★ **能编码 → 隐式图 → BFS 求最短。**

### ★ 三种输入形式 → 图形状

| 输入 | 图 |
|---|---|
| `[[1,0],[2,1]]` 前置 | **有向图** |
| `isConnected[i][j]` | **无向图（邻接矩阵）** |
| `rooms[i] = [keys]` | **有向图** |
| `edges = [[u,v,w]]` | **带权图** |
| 网格 `grid[i][j]` | **隐式网格图** |
| `wordList` + 「差一个字母」 | **隐式字符串图** |

### ★ 问什么 → 用什么算法

| 问什么 | 算法 |
|---|---|
| 有几个**连通块** / 分几组 | **DFS/BFS / 并查集** |
| 从 A **能否到达** B | **DFS/BFS** |
| **最短**多少步 | **BFS**（无权）/ Dijkstra（带权）|
| **有没有环** / 能否全部完成 | **拓扑排序 / DFS 三色** |
| 一个**顺序**使依赖满足 | **拓扑排序** |
| 两点**是否同一组**（动态合并）| **并查集** |

### ⚠️ 反例：什么时候不是图

| 题目特征 | 为什么不用图 |
|---|---|
| 「连续子数组」类 | 位置是线性顺序，**没有分叉** → 滑窗/前缀和 |
| 「排序后处理」类 | 关系是全序，**没有图结构** |
| 「单一路径」类 | 只有一条路 → 直接扫 |

★★ **最深层判据：关系是「线性的」还是「网状的」？**
- 线性（只有前后）→ 扫一遍
- **网状（多个方向）→ 图**

★ **图是「通用但重」的工具** —— 能用数组/哈希/滑窗解决就不要上图。

### ★ 练习：判断是不是图

| 题 | 是否图 | 用什么 |
|---|---|---|
| 1. 两数之和（有序）| ❌ | 对撞双指针 |
| 2. 课程表 | ✅ 有向图 | 拓扑排序 |
| 3. 最长连续序列 | ❌ | 哈希集合 |
| 4. 岛屿数量 | ✅ 网格隐式图 | DFS/BFS |
| 5. 单词接龙 | ✅ 隐式字符串图 | BFS + 模式匹配 |
| 6. 合并区间 | ❌ | 排序 + 贪心 |
| 7. 打开转盘锁 | ✅ 状态空间图 | BFS |
| 8. 和为 K 的子数组 | ❌ | 前缀和 + 哈希 |
| 9. 被围绕的区域（130）| ✅ 网格 + 边界连通 | DFS |
| 10. 省份数量 | ✅ 邻接矩阵 | DFS 连通分量 |

★ **规律：「连续区间/子数组」→ 不是图；「状态/依赖/连通/相邻」→ 是图。**

## 一、图的存储

### 1.1 邻接矩阵（二维数组）

```cpp
int g[n][n];              // g[u][v] = 1 表示 u→v 有边（或边权）
```

| 优点 | 缺点 |
|---|---|
| O(1) 判断两点是否相邻 | **O(n²) 空间** |
| 写法直白 | 稀疏图浪费严重 |

★ **适用**：稠密图 / 节点少（n ≤ 1000）/ 需要频繁判断两点是否相邻。

### 1.2 ★ 邻接表（最常用）

```cpp
vector<vector<int>> g(n);      // g[u] = u 的所有邻居
g[u].push_back(v);             // 加边 u→v
g[v].push_back(u);             // 无向图再加反向

for (int v : g[u]) { ... }     // ★ 遍历 u 的邻居
```

| 优点 | 缺点 |
|---|---|
| **O(n + m) 空间**（m = 边数）| 判断两点相邻要 O(度数) |

★ **适用**：绝大多数题（稀疏图）。

### 1.3 带权图

```cpp
// 方式 1：pair（终点, 权值）
vector<vector<pair<int,int>>> g(n);
g[u].push_back({v, w});

for (auto [v, w] : g[u]) { ... }

// 方式 2：结构体
struct Edge { int to, w; };
vector<vector<Edge>> g(n);
```

### 1.4 有向 vs 无向

```cpp
// 无向图：加两条
g[u].push_back(v);
g[v].push_back(u);

// 有向图：只加一条
g[u].push_back(v);
```

⚠️ **忘加反向边 → 无向图变成有向 → 遍历不连通。**

## 二、图的遍历

### 2.1 ★ 关键差异：必须用 `visited`

★ **树无环 → 不用 `visited`；图有环 → 必须用。**

```cpp
vector<bool> visited(n, false);
```

⚠️ **不加 `visited` → 环上无限递归 → 爆栈。**

### 2.2 DFS（递归）

```cpp
void dfs(int u) {
    visited[u] = true;              // ★ 进入即标记
    for (int v : g[u]) {
        if (!visited[v]) dfs(v);
    }
}
```

### 2.3 BFS（求最短步数）

```cpp
void bfs(int start) {
    queue<int> q;
    q.push(start);
    visited[start] = true;
    int step = 0;

    while (!q.empty()) {
        int sz = q.size();
        for (int k = 0; k < sz; k++) {
            int u = q.front(); q.pop();
            for (int v : g[u]) {
                if (visited[v]) continue;
                visited[v] = true;       // ★ 入队时标记
                q.push(v);
            }
        }
        step++;
    }
}
```

### 2.4 遍历所有连通分量

```cpp
int components = 0;
for (int i = 0; i < n; i++) {
    if (!visited[i]) {
        components++;              // ★ 新连通分量
        dfs(i);
    }
}
```

★ **典型题：省份数量（547）、岛屿数量（200）都是这个模式。**

## 三、★ 网格题 = 图题（统一视角）

★ **网格是「隐式图」**：每个格子是节点，四方向相邻就是边。

| | 显式图 | 网格（隐式图） |
|---|---|---|
| 节点 | `0..n-1` | `(i, j)` 坐标 |
| 邻居 | `g[u]` | `(i±1, j)` / `(i, j±1)` |
| 标记 | `visited[u]` | 原地改 `grid` 或 `visited[i][j]` |
| 遍历 | 同一个 DFS/BFS | 同一个 DFS/BFS |

★ **所以 200 岛屿 / 994 橘子 / 542 矩阵，本质都是图遍历。**

## 四、拓扑排序（有向无环图 DAG）

### 4.1 什么时候用

★ **信号：「有先后依赖」+「能不能完成所有任务」。**

```
课程表：修课程 A 前必须先修 B、C → 有向边 B→A, C→A
问：能否修完所有课？（= 是否有环）
```

### 4.2 BFS 版（Kahn 算法）

```cpp
vector<int> indegree(n, 0);
for (u) for (v : g[u]) indegree[v]++;     // 统计入度

queue<int> q;
for (i) if (indegree[i] == 0) q.push(i);  // ★ 入度为 0 的先入队

int done = 0;
while (!q.empty()) {
    int u = q.front(); q.pop();
    done++;
    for (int v : g[u]) {
        if (--indegree[v] == 0) q.push(v);   // ★ 入度归零才能入队
    }
}
return done == n;      // ★ 全部处理完 = 无环
```

### 4.3 ★ 判环的等价说法

```
拓扑排序能处理完所有节点 ⟺ 图无环（DAG）
处理不完 ⟺ 存在环
```

### 4.4 DFS 版（三色标记）

```cpp
// 0 = 未访问, 1 = 访问中, 2 = 已完成
bool dfs(int u) {
    if (state[u] == 1) return false;      // ★ 又回到「访问中」的 → 有环
    if (state[u] == 2) return true;
    state[u] = 1;
    for (int v : g[u]) if (!dfs(v)) return false;
    state[u] = 2;
    return true;
}
```

★ **`state == 1` 二次遇到 = 有环** —— 这是 DFS 判环的核心。

## 五、案例（本人独立完成）

### 5.1 省份数量（547）—— 邻接矩阵 + 连通分量

```cpp
int findCircleNum(vector<vector<int>>& g) {
    int n = g.size(), count = 0;
    vector<bool> visited(n, false);
    for (int i = 0; i < n; i++)
        if (!visited[i]) { count++; dfs(g, visited, i); }
    return count;
}
void dfs(vector<vector<int>>& g, vector<bool>& visited, int u) {
    visited[u] = true;
    for (int j = 0; j < (int)g.size(); j++)
        if (g[u][j] == 1 && !visited[j]) dfs(g, visited, j);   // ★ g[u][j] 是 0/1 标记
}
```

⚠️ **本人踩坑**：写成 `vector<int> neighbor = g[u]; for (i) dfs(neighbor[i])` —— **把 0/1 标记当成了节点编号。**

★ **邻接矩阵 vs 邻接表的语义差异（最容易混）：**
| | 邻接表 `vector<vector<int>> g` | 邻接矩阵 `vector<vector<int>> g` |
|---|---|---|
| `g[u]` | **u 的邻居列表**（节点编号）| **一行 0/1 标记** |
| 遍历邻居 | `for (int v : g[u])` | **`for (j) if (g[u][j] && !visited[j])`** |

### 5.2 钥匙和房间（841）—— 有向图可达性

```cpp
bool canVisitAllRooms(vector<vector<int>>& rooms) {
    int n = rooms.size();
    vector<bool> visited(n, false);
    dfs(rooms, visited, 0);                 // ★ 只从 0 出发
    for (bool v : visited) if (!v) return false;
    return true;
}
void dfs(vector<vector<int>>& rooms, vector<bool>& visited, int u) {
    visited[u] = true;
    for (int v : rooms[u]) if (!visited[v]) dfs(rooms, visited, v);
}
```

★ **`rooms` 本身就是邻接表** —— `rooms[i]` 直接就是房间 `i` 能去的房间。
★ **与 547 的差异：只有一个起点（不用外层 for），问「能否到全部」而非「有几个分量」。**

### 5.3 课程表（207）/ 课程表 II（210）—— 拓扑排序（Kahn）

```cpp
bool canFinish(int n, vector<vector<int>>& pre) {          // 210 把 return 换成 return order
    vector<vector<int>> g(n);
    vector<int> indegree(n, 0);

    for (auto& p : pre) {
        int a = p[0], b = p[1];         // ★ b 是 a 的前置 → 边 b → a
        g[b].push_back(a);
        indegree[a]++;                   // ★ 入度加在【后继】上
    }

    queue<int> q;
    for (int i = 0; i < n; i++) if (indegree[i] == 0) q.push(i);   // ★ 入度 0 先入队

    int done = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        done++;                                                   // 210: order.push_back(u)
        for (int v : g[u])
            if (--indegree[v] == 0) q.push(v);                    // ★ 归零才入队
    }
    return done == n;                    // ★ 处理完所有 = 无环
}
```

★ **入度 = 「还有几个前置没完成」** —— 可以是 0、1、2、3...（不是只有 0/1）。
★ **有环 → 环上节点入度永远降不到 0 → `done < n`。**

⚠️ **本人踩坑（207）**：
1. **没有建邻接表** —— 每次出队都扫全部 `prerequisites` 找邻居 → **O(n·m)**，而且 `if (入度为0) 入队` 写在了 `if (是邻居)` 外面 → 重复入队。
2. 修法：**先建好 `g[b].push_back(a)`**，之后只遍历 `g[u]`。

### 5.4 单词接龙（127）—— 隐式图 BFS + 模式匹配

**题意**：每次改一个字母，词在字典里，求 `beginWord → endWord` 的最短序列长度。

**建图（隐式）**：节点 = 词，边 = 「只差一个字母」。

#### 写法 A：朴素（618ms）
```cpp
for (auto it = dict.begin(); it != dict.end(); ) {
    if (canConvert(cur, *it)) {        // ★ O(L) 比较
        q.push(*it);
        it = dict.erase(it);            // ★ 删除 = 标记已访问
    } else ++it;
}
```
★ **总复杂度 O(n²·L)**。

#### ★ 写法 B：模式匹配（80ms）
```cpp
// 预处理：把每个词拆成 L 个模式
unordered_map<string, vector<string>> patternMap;
for (string& w : wordList)
    for (int i = 0; i < w.size(); i++) {
        string p = w; p[i] = '*';
        patternMap[p].push_back(w);      // 同模式的词互为邻居
    }

// BFS
unordered_set<string> visited;
visited.insert(beginWord);
while (!q.empty()) {
    ...
    for (int k = 0; k < cur.size(); k++) {
        string p = cur; p[k] = '*';
        for (string& w : patternMap[p]) {
            if (visited.count(w)) continue;    // ★★★ 必需
            visited.insert(w);
            q.push(w);
        }
        patternMap[p].clear();              // 优化：该模式用完就清
    }
}
```

★ **核心洞察：「只差一个字母」⟺ 「共享同一个通配模式」**

| | 写法 A | 写法 B |
|---|---|---|
| 找邻居 | **O(n·L)** | **O(L²)** |
| 总复杂度 | **O(n²·L)** | **O(n·L²)** |
| 空间 | O(n) | **O(n·L)**（模式表）|

#### ★ 5.4.1 `visited` 与 `clear()` 各管什么（两人容易混）

| 机制 | 防的是什么 | 能否互换 |
|---|---|---|
| **`visited`** | **同一个词被多个路径发现**（词级别去重）| ❌ 必需 |
| **`clear()`** | **同一个模式被多次扫描**（模式级别去重）| ❌ 仅优化 |

⚠️ **本人踩坑**：改用模式匹配后**忘了 `visited`** → 同一词被多个模式反复入队 → **队列爆炸 → MLE**。

#### ★ 5.4.2 为什么 `clear()` 不影响正确性

★ **因为 `clear()` 发生在「已经遍历完 `patternMap[p]` 全部元素」之后。**

```
处理 cur 时，模式 p = "*ot"
patternMap["*ot"] = ["hot", "dot"]
→ 遍历：hot 已访问跳过；dot 未访问 → 标记 + 入队
→ 此时 dot 已经在队列里了
→ clear()
→ 之后任何词再遇到 "*ot"：表为空 → 什么也不做
→ 但 dot 已经在队列里 → 不影响结果
```

★ **图论说法：删掉「已经走过的边」不影响可达性。**
★ **保守做法：不清空也能对（`visited` 会挡住），只是多扫几遍。**

## 六、⚠️ 避坑清单

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | **忘记 `visited`** | 图有环 → 必须标记 |
| 2 | 无向图只加一条边 | `g[u].push_back(v); g[v].push_back(u);` |
| 3 | `visited` 在出队时标记（BFS）| **入队时标记** |
| 4 | 只从一个点开始遍历 | 外层 `for` 检查所有未访问节点（连通分量）|
| 5 | 拓扑排序忘记 `--indegree` | 入度归零才入队 |
| 6 | 拓扑排序不检查 `done == n` | 判环靠这个 |
| 7 | 节点编号 1-based 忘了转 | `u-1` 或数组开 `n+1` |
| 8 | 邻接矩阵 vs 邻接表选错 | 稀疏用表，稠密/频繁判邻接用矩阵 |
| 9 | **把邻接矩阵的 0/1 当成节点编号** | `if (g[u][j] == 1) dfs(j)`，不是 `dfs(g[u][i])` —— 本人踩坑（547）|
| 10 | **不建邻接表，每次扫全部边** | O(n·m) → 先 `g[b].push_back(a)` —— 本人踩坑（207）|
| 11 | **拓扑排序的入队 `if` 写在邻居判断外面** | 只在「u 的邻居」上 `--indegree` 并判零 |
| 12 | **模式匹配忘了 `visited`** | `clear()` 只防重复扫描，不防重复入队 → MLE —— 本人踩坑（127）|
| 13 | **边方向搞反** | 判据：读成「从 X 能到 Y」，边就是 X→Y |

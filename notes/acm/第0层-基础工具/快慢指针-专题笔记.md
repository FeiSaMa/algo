★ **存值 → 丢失位置信息 → 无法判断过期。**

**存下标的两条性质：**

| 性质         | 说明                 | 用途                                |
| ------------ | -------------------- | ----------------------------------- |
| **下标递增** | 后进的必然更大       | 队首最老 → **只弹队首**就能清理过期 |
| **值递减**   | 踢掉小的之后自然形成 | 队首最大 → `nums[front]` 就是答案   |

## 〇、一句话总纲

★ **快慢指针：两个指针同向移动，快指针负责「读」，慢指针负责「写」。**

```
[ a, b, c, d, e ]
  ↑     ↑
 slow  fast
  写     读
```

★ **核心用途（数组版）：原地修改数组，O(n) 时间 + O(1) 空间。**

★ **与另外两种双指针的区别**：

| 类型 | 方向 | 用途 |
|---|---|---|
| 滑动窗口 | 同向 | 连续区间 + 状态维护 |
| 对撞 | 相向 | 首尾配对 |
| **快慢** | **同向，不同速/不同职责** | **原地去重 / 移动元素** |

---

## 一、核心思想：「读」和「写」分离

★ **快指针 `fast` 扫描整个数组（读）；慢指针 `slow` 标记「下一个要写入的位置」（写）。**

```
nums = [1, 1, 2, 2, 3]
slow=0, fast=0

fast=0: nums[0]=1 → 写 nums[slow=0] = 1，slow=1
fast=1: nums[1]=1 → 重复，跳过
fast=2: nums[2]=2 → 写 nums[slow=1] = 2，slow=2
...
```

★ **关键：`slow` 之前的区域是「已处理好的结果」，`fast` 之后是「未读的」。**

```
[ 已处理 | 待写位置 | ...未读... ]
         ↑          ↑
        slow       fast
```

## 二、三道已做题目

### 2.1 删除有序数组中的重复项（26）

★ **要求**：原地删除重复元素，返回新长度（**不能**用额外数组）。

```cpp
int removeDuplicates(vector<int>& nums) {
    if (nums.empty()) return 0;
    int slow = 1;                      // ★ 第一个元素一定保留
    for (int fast = 1; fast < (int)nums.size(); fast++) {
        if (nums[fast] != nums[slow - 1]) {      // ★ 和「已保留的最后一个」比
            nums[slow] = nums[fast];
            slow++;
        }
    }
    return slow;                        // ★ 返回长度 = slow
}
```

★ **关键点**：
- `slow` 从 **1** 开始（第一个元素直接保留）
- 比较对象是 **`nums[slow-1]`**（已保留部分最后一个），不是 `nums[fast-1]`
- 返回 **`slow`**（新长度），不是 `slow+1`

### 2.2 移除元素（27）

★ **要求**：原地删除所有等于 `val` 的元素，返回新长度。

```cpp
int removeElement(vector<int>& nums, int val) {
    int slow = 0;
    for (int fast = 0; fast < (int)nums.size(); fast++) {
        if (nums[fast] != val) {
            nums[slow] = nums[fast];
            slow++;
        }
    }
    return slow;
}
```

★ **这是最纯粹的快慢指针模板** —— 记住这个骨架。

### 2.3 移动零（283）

★ **要求**：把所有 0 移到末尾，**保持非零元素相对顺序**。

```cpp
void moveZeroes(vector<int>& nums) {
    int slow = 0;
    for (int fast = 0; fast < (int)nums.size(); fast++) {
        if (nums[fast] != 0) {
            swap(nums[slow], nums[fast]);      // ★ 交换（不是赋值）
            slow++;
        }
    }
}
```

★ **和 27 的区别**：27 是「覆盖」（丢掉不要的），283 是「交换」（保序 + 把 0 留后面）。

★ **也可以写赋值版**（先搬非零，再补零）：

```cpp
int slow = 0;
for (int fast = 0; fast < n; fast++)
    if (nums[fast] != 0) nums[slow++] = nums[fast];
while (slow < n) nums[slow++] = 0;    // 补零
```

## 三、★ 三题对比（核心）

| | 26 删除重复 | 27 移除元素 | 283 移动零 |
|---|---|---|---|
| `slow` 初值 | **1** | 0 | 0 |
| 判定条件 | `nums[fast] != nums[slow-1]` | `nums[fast] != val` | `nums[fast] != 0` |
| 写入方式 | 赋值 | 赋值 | **swap**（或赋值+补零）|
| 返回 | 新长度 `slow` | 新长度 `slow` | `void`（原地改）|
| 保序 | ✅ | ✅ | ✅ |

★ **共同骨架**：

```cpp
int slow = 0;  // 或 1
for (int fast = 0; fast < n; fast++) {
    if (保留条件) {
        写 nums[slow]（赋值或 swap）;
        slow++;
    }
}
```

## 四、⚠️ 避坑清单

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | 返回 `slow+1` | 返回 **`slow`**（它已经指向「结果长度」）|
| 2 | 26 里 `slow` 从 0 开始 | 从 **1** 开始（第一个必留）|
| 3 | 26 里和 `nums[fast-1]` 比 | 和 **`nums[slow-1]`** 比（已保留的最后一个）|
| 4 | 283 用赋值丢顺序 | 用 **`swap`**（或用赋值 + 最后补零）|
| 5 | 空数组没处理 | 26 要特判 `nums.empty()` |
| 6 | 用额外数组（题目要求原地）| **不 new 新数组**，只改原数组前 `slow` 个位置 |

## 五、待学（链表版）

★ **同样的「快慢」思想，用在链表上是另一种用途**：

| 用途 | 快慢速度 | 典型题 |
|---|---|---|
| **判环** | fast 走 2 步，slow 走 1 步 | 环形链表（141 / 142）|
| **找中点** | fast 走 2 步，slow 走 1 步 | 链表的中间结点（876）|
| **找倒数第 N 个** | fast 先走 N 步，再同步走 | 删除链表的倒数第 N 个结点（19）|

★ **核心原理（判环）**：如果链表有环，快指针一定会在环里「追上」慢指针。

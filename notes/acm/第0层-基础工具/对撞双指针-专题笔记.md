## 〇、一句话总纲

★ **对撞双指针：两个指针从两端相向移动，每步「确定性地排除一端」，直到相遇。O(n)。**

```
[ a, b, c, d, e, f ]
  ↑                 ↑
 left              right
     →         ←
```

★ **与同向双指针（滑窗）对比**：

| | 同向（滑窗）| 对撞 |
|---|---|---|
| 起点 | 都从左边 | **一左一右** |
| 移动 | 同方向 | **相向** |
| 结束 | 到末尾 | **相遇** |
| 用途 | 连续区间 | **首尾配对 / 收缩 / 反向填充** |

## 一、★ 什么时候能用（核心前提）

★ **必须能回答：当前这一对的结果，能告诉我「该动哪一端」吗？**

```
如果当前组合「太小」→ 动 left（往大的方向）
如果当前组合「太大」→ 动 right（往小的方向）
```

★ **而且「动一端」必须能「安全排除」那一端的所有可能** —— 否则会漏解。

```text
不能确定性地排除一端 → 对撞不成立
```

★ **这通常需要「有序」或「单调关系」** —— 否则不知道该动哪边。

### 1.1 ★ 三种「动哪边」的判据

| 题 | 判据 | 排除理由 |
|---|---|---|
| **167 / 15** | `sum < target` → `left++` | 有序：`nums[left]` 太小，和它配的更小 → 这一**行**全废 |
| **167 / 15** | `sum > target` → `right--` | 有序：`nums[right]` 太大 → 这一**列**全废 |
| **11 盛水** | **矮的往中间移** | 宽度只会减小，移高的只让 `min` 变小或不变 → 不可能更好 |

★ **11 的推理值得记**：
```
面积 = min(左高, 右高) × 宽度
宽度单调递减 → 想变大只能靠 min 变大
移高的 → min 不变或更小，宽度还减 → 面积只会变小 → 无意义
移矮的 → min 可能变大 → 还有希望
```

## 二、★ 为什么要「排序」（以及什么时候不能排序）

| 题 | 排序 | 原因 |
|---|---|---|
| 167 | 题目已给有序 | — |
| 三数之和（15） | ✅ **必须** | 值重要：有序才能对撞 + 去重 + 剪枝 |
| 977 | 题目已给有序 | — |
| **11 盛水** | ❌ **绝不能** | **位置重要**（宽度 = 下标差），排序会打乱 |

★ **判据：答案依赖「位置的相对关系」吗？**
- 依赖（宽度、距离、下标差）→ **不能排序**
- 只看「值」→ 可以排序（通常必须排）

## 三、四种变体

### 变体 1：两数之和（母题）

```cpp
int left = 0, right = n - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) return {left + 1, right + 1};
    else if (sum < target) left++;      // 太小 → 增大
    else right--;                        // 太大 → 减小
}
```

### 变体 2：反向填充（977 有序数组平方）

★ **从两端比较，把「更大的」放到结果数组的末尾。**

```cpp
int left = 0, right = n - 1, pos = n - 1;
while (left <= right) {                    // ★ <= ：每个元素都要处理
    int lv = nums[left]  * nums[left];
    int rv = nums[right] * nums[right];
    if (lv >= rv) { ans[pos--] = lv; left++; }
    else          { ans[pos--] = rv; right--; }
}
```

### 变体 3：外层固定 + 内层对撞（15 三数之和）

★ **排序 → 固定第一个数 → 内层对撞找另两个 → 三处去重。**

### 变体 4：移动矮柱子（11 盛水）

★ **每步移动较矮的一端。**

## 四、案例

### 4.1 有序数组的平方（977）

★ **洞察：平方后最大的值一定在「两端之一」**（绝对值最大的在两端）→ 从末尾往前填。

```cpp
vector<int> sortedSquares(vector<int>& nums) {
    int n = nums.size();
    vector<int> ans(n);
    int left = 0, right = n - 1, pos = n - 1;
    while (left <= right) {
        int lv = nums[left] * nums[left], rv = nums[right] * nums[right];
        if (lv >= rv) { ans[pos--] = lv; left++; }
        else          { ans[pos--] = rv; right--; }
    }
    return ans;
}
```

⚠️ **本人坑**：`size_t right = nums.size() - 1` → 空数组回绕；`pow(x, 2)` 应改成 `x * x`。

### 4.2 两数之和 II（167）

```cpp
vector<int> twoSum(vector<int>& numbers, int target) {
    int left = 0, right = (int)numbers.size() - 1;
    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target) return {left + 1, right + 1};   // ★ 1-based
        else if (sum < target) left++;
        else right--;
    }
    return {};
}
```

### 4.3 三数之和（15）（★ 三处去重）

```cpp
vector<vector<int>> threeSum(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    vector<vector<int>> ans;
    int n = nums.size();
    for (int i = 0; i < n - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;     // ① 外层去重
        if (nums[i] > 0) break;                             // 剪枝（依赖排序）

        int left = i + 1, right = n - 1;                    // ★ 只往右找 → 天然去重
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum < 0) left++;
            else if (sum > 0) right--;
            else {
                ans.push_back({nums[i], nums[left], nums[right]});   // ★ 存【值】
                while (left < right && nums[left]  == nums[left + 1])  left++;    // ②
                while (left < right && nums[right] == nums[right - 1]) right--;   // ③
                left++;
                right--;
            }
        }
    }
    return ans;
}
```

#### ★ 4.3.1 去重的完整原理

★ **重复的根源**：值相同的多个**下标**，能组成「值相同」的同一个三元组。

★ **去重原则：值相同的元素，只用第一个（排序后相邻）。**

| 层 | 位置 | 写法 |
|---|---|---|
| ① | 外层 `i` | `if (i > 0 && nums[i] == nums[i-1]) continue;` |
| ② | 内层 `left` | `while (left < right && nums[left] == nums[left+1]) left++;` |
| ③ | 内层 `right` | `while (left < right && nums[right] == nums[right-1]) right--;` |

★ **两条铁律**：
- ★ **去重必须在 `push_back` 之后**（先记录当前这个，再跳到下一个不同的值）
- ★ **`left < right` 必须放 `&&` 左边**（短路防越界）

★ **`left = i + 1` 天然去重**：只在 `i` 右边找 → 保证 `i < left < right` 顺序唯一 → 同一组三个数的不同排列不会重复。

#### ★ 4.3.2 对称表（防手滑）

| | 比较 | 移动 |
|---|---|---|
| left 去重 | `nums[left] == nums[left + 1]` | **`left++`** |
| right 去重 | `nums[right] == nums[right - 1]` | **`right--`** |

⚠️ **本人踩坑**：写成 `while (... nums[right] == nums[right-1]) left--;` → `left` 越退越小 → 越界读垃圾值 → `INT_MIN - 1` 溢出（UBSan 报错）。

### 4.4 盛最多水的容器（11）

```cpp
int maxArea(vector<int>& height) {
    int left = 0, right = (int)height.size() - 1;
    int best = 0;
    while (left < right) {
        int area = min(height[left], height[right]) * (right - left);
        best = max(best, area);
        if (height[left] <= height[right]) left++;    // ★ 移动矮的
        else right--;
    }
    return best;
}
```

★ **不排序**（宽度依赖位置）。

#### ★ 4.4.1 为什么移动「较矮」的？（完整推理）

★ **面积 = min(左高, 右高) × 宽度**

```
前提：宽度 = right - left，指针往中间走 → 宽度【只会减小】
→ 想让面积变大，只能靠 min(左高, 右高) 变大
```

**分情况：**

| 移动哪端 | min 的变化 | 宽度 | 面积 |
|---|---|---|---|
| **移高的** | **不变或更小**（矮的还在限制）| **减小** | **只会变小 → 无意义** |
| **移矮的** | **可能变大**（换根更高的上来）| 减小 | 还有希望 |

★ **结论：移高的那一对（当前矮柱 + 其他任何柱子）都不可能优于当前，所以可以直接排除。**

★ **这也是「每步确定性排除一端」的具体体现** —— 被移走的那一端，它与当前另一端的组合已经是「该端能贡献的极限」了。

★ **一句话：矮的那根是瓶颈，移走它才有可能改善；移走高的，瓶颈还在且宽度更小。**

## 五、⚠️ 避坑清单

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | **找到解后不推进指针 → 死循环** | `left++; right--;`（15 的 MLE 就是这样）|
| 2 | **左右对称操作写反** `left--` / `right++` | left 去重配 `left++`，right 配 `right--` |
| 3 | **去重放在 `push_back` 之前** | 先记录，再去重 |
| 4 | `while (nums[left] == nums[left+1] && left < right)` | **`left < right` 必须放左边**（短路）|
| 5 | 15 存下标而非值 | `push_back({nums[i], nums[left], nums[right]})` |
| 6 | 15 忘了外层去重 | `if (i > 0 && nums[i] == nums[i-1]) continue;` |
| 7 | **11 或 977 误排序** | 11 位置重要，**绝不能排序** |
| 8 | 977 用 `pow(x, 2)` | `x * x`（`pow` 是浮点函数，慢且可能不精确）|
| 9 | `size_t right = v.size() - 1` | 空容器回绕 → 用 `int` 下标 |
| 10 | 循环条件 `<=` vs `<` | 允许用同一个元素时 `<=`（977）；不允许时 `<`（167/15/11）|

## 七、一句话总结

> ★ **对撞双指针：两端相向移动，每步「确定性排除一端」，O(n)。**
>
> ★ **能用它的前提：当前结果能告诉你「动哪端」，且动一端能安全排除那一端的所有可能。**
>
> ★ **三种判据**：
> - 有序 + 和太小/太大 → 动 left / right（167、15）
> - **移动矮的那端**（11，宽度单调递减）
> - **从两端取最大往末尾填**（977）
>
> ★ **排序**：15 必须排；**11 绝不能排**（位置重要）。
>
> ★ **15 的三处去重 + 去重在 `push_back` 之后 + `left < right` 放左边。**
>
> ★ **`while` 里找到答案却不推进指针 → 死循环**（最常见的一类死循环）。

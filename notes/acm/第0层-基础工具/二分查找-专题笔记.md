## 〇、一句话总纲

★ **二分 = 在「单调序列」上找「翻转点」（第一个满足某条件的位置），O(log n)。**

```
[假 假 假 真 真 真]     ← 条件：nums[i] >= target
              ↑
        二分找这个「假→真」的翻转点
```

★ **关键认知：二分的前提不是「数组有序」，而是「存在单调性 / 翻转点」。**
→ 这直接引出**二分答案**（对「答案空间」二分）。

---

## 一、为什么需要二分

### 1.1 从「暴力查找」说起

```
有序数组找 target：
  暴力：从前往后扫 → O(n)
  二分：每次排除一半 → O(log n)
```

★ **n = 10⁶ 时，O(n) = 10⁶ 次，O(log n) ≈ 20 次** —— 差距巨大。

### 1.2 ★ 二分的真正前提：单调性（不是「有序」）

★ **有单调性才能二分。** 「有序」只是「单调性」的一个特例。

```
普通二分：数组有序 → nums[i] 关于 i 单调
二分答案：答案越大越容易满足条件 → can(答案) 关于答案单调
```

★ **判据：能不能找到一个「分界点」，左边全不满足、右边全满足。**

## 二、两套体系（⚠️ 别混用！）

### 体系 A：闭区间 `[left, right]`

```cpp
int left = 0, right = n - 1;          // right 是「有效下标」
while (left <= right) {               // ★ <=
    int mid = left + (right - left) / 2;
    if (nums[mid] == target) return mid;
    else if (nums[mid] < target) left = mid + 1;
    else right = mid - 1;
}
return -1;
```

### 体系 B：半开 `[left, right)` ★ 推荐

```cpp
int left = 0, right = n;              // right 是「无效边界」，多一格
while (left < right) {                // ★ <
    int mid = left + (right - left) / 2;
    if (nums[mid] >= target) right = mid;
    else left = mid + 1;
}
return left;                          // left ∈ [0, n]，即「翻转点」
```

★ **两者都正确，但混用必崩。** 本笔记**统一用半开 `[left, right)`**（和 STL 一致，边界更好处理）。

★ **半开的好处**：`right = n` 给「全不满足」留了合法收敛点 `n`；不用特判「找不到」。

## 三、★ 边界铁律：`mid` 取整方向 vs 赋值方向

### 3.1 防溢出

```cpp
int mid = (left + right) / 2;             // ⚠️ left + right 可能溢出 int
int mid = left + (right - left) / 2;      // ✅ 不溢出（推荐）
```

### 3.2 ★ 核心：取整方向决定哪个赋值安全

★ **`mid = left + (right-left)/2`（向下取整）保证**：

```
mid >= left     （可能相等！）
mid <  right    （严格小于）
```

| 取整方向 | 与 left | 与 right | 安全赋值 | 危险赋值 |
|---|---|---|---|---|
| **向下 `(l+r)/2`** | `mid >= left`（可能等）| `mid < right` | **`right = mid`** | `left = mid` ❌ 死循环 |
| **向上 `(l+r+1)/2`** | `mid > left` | `mid <= right`（可能等）| **`left = mid`** | `right = mid` ❌ 死循环 |

★ **记忆**：
- 向下取整偏「左」→ 能安全把 **right 拉下来**（`right = mid`）
- 向上取整偏「右」→ 能安全把 **left 推上去**（`left = mid`）

### 3.3 ⚠️ 本人踩坑：`left = mid` + 向下取整 → 死循环

```cpp
// ❌ 找「最后一个 <= target」时写下，超时！
int mid = left + (right - left) / 2;   // 向下取整
if (nums[mid] <= target) left = mid;   // left = mid
else right = mid - 1;
```

**现象**：`left=0, right=1` 时 `mid = 0`；若 `nums[0] <= target` → `left = mid = 0` **没变** → 死循环。

★ **根因**：向下取整时 `mid` 可能 `== left`，`left = mid` 不推进。

★ **修法两种**：
- **A**：改向上取整 `mid = left + (right-left+1)/2`
- **B（推荐）**：**换成 `right = mid` 的写法**（把「找最后一个 <= target」改成「找第一个 > target」再 `-1`）

## 四、★ 模板：`lower_bound` / `upper_bound`（两段同构）

★ **两段结构完全一样，只差一个符号** —— 这就是 STL 的实现。

```cpp
// 第一个 >= target
int lowerBound(vector<int>& nums, int target) {
    int left = 0, right = nums.size();
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] >= target) right = mid;   // ★ 满足 → 保留 mid，往左
        else left = mid + 1;
    }
    return left;                                 // 第一个 >= target，或 n
}

// 第一个 > target（★ 只改 >= 为 >）
int upperBound(vector<int>& nums, int target) {
    int left = 0, right = nums.size();
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] > target) right = mid;
        else left = mid + 1;
    }
    return left;                                 // 第一个 > target，或 n
}
```

★ **为什么两段都用 `right = mid`** → 配向下取整，**永不死循环**（区间严格缩小）。

### 4.1 ★ 「找不到」怎么判

★ **二分只找「位置」，不管「值相不相等」** —— 判存在是调用者的事。

```cpp
int pos = lowerBound(nums, target);
if (pos == n || nums[pos] != target) { /* 不存在 */ }
```

| 情况 | 含义 |
|---|---|
| `pos == n` | 所有元素都 `< target`（全假）|
| `nums[pos] != target` | 第一个 `>= target` 的值 `> target`（target 不在）|
| `nums[pos] == target` | ✅ target 存在，`pos` 就是第一个位置 |

★ **一句话：二分找位置，验证判存在。**

### 4.2 ★ 要「位置」不用验证，要「值相等」才验证

| 题目要什么 | 验证 | 例 |
|---|---|---|
| **插入位置** | ❌ 不用 | 35（直接返回 `left`）|
| **target 的下标** | ✅ 要 | 34（`pos==n \|\| nums[pos]!=target`）|

## 五、★ 二分答案（二分的通用形态）

### 5.1 核心思想

★ **对「答案的可能取值」二分，条件是「这个候选答案可行吗」。**

```
can(x) 对 x 单调：  假 假 假 真 真 真
                          ↑ 找这个翻转点 = 最小（或最大）可行答案
```

★ **「二分答案」= 把「数组下标」换成「答案取值」，把「比较」换成「`can()` 判定」。** 骨架同 `lower_bound`。

### 5.2 模板

```cpp
int left = 最小可能答案, right = 最大可能答案;
while (left < right) {
    int mid = left + (right - left) / 2;
    if (can(mid)) right = mid;      // mid 可行 → 答案可能更小 → 往左
    else left = mid + 1;            // mid 不可行 → 答案更大
}
return left;                         // 第一个可行的答案
```

★ **注意 `right = mid`（不是 `mid - 1`）** —— 和 `lower_bound` 一样：mid 可行**可能**就是答案，保留。

### 5.3 ★ 识别信号

| 信号 | 说明 |
|---|---|
| 「最小化最大值」/「最大化最小值」| ★ 典型二分答案 |
| 答案是一个整数，且有范围 | 可二分 |
| **答案越大/越小，越容易满足条件** | ★ 单调性（可行性）|

## 六、★ 贪心简述（1011 / 410 的 `can` 用到）

### 6.1 什么是贪心

★ **贪心（Greedy）：每一步都选「当前看起来最优」的，不回头、不反悔。**

```
贪心 = 局部最优 → 希望推出全局最优
```

| 思想 | 特点 |
|---|---|
| 暴力 | 尝试所有可能 |
| **贪心** | **每步只看眼前最优，一次决定，不回头** |
| DP | 记录子问题解，从多条路里选 |

### 6.2 ⚠️ 贪心「可能错」—— 关键认知

★ **只在「局部最优 → 全局最优」成立时才对。**

**反例（凑零钱）**：面额 `[1,3,4]` 凑 6
```
贪心（每次拿最大）：4+1+1 = 3 枚
最优：            3+3   = 2 枚   ← 贪心错了
```

★ **用贪心前必问：这一步的选择会不会害了后面？会 → 不能用。**

### 6.3 ★ 1011 / 410 里的贪心（分段）

```
从左到右累加，超过上限就切一段（新段从当前元素开始）
```

★ **为什么这里贪心对**：题目要求「连续分段」，且「一段装得越多，段数越少越好」→ 能装就装没有副作用。

★ **⚠️ 切的时候必须重置累加器为【当前元素】**（不是清零！）—— 本人踩坑见 §八。

## 七、案例

### 7.1 34 查找首末位置（lower + upper）

```cpp
vector<int> searchRange(vector<int>& nums, int target) {
    int n = nums.size();
    int first = lowerBound(nums, target);    // 第一个 >= target
    int last  = upperBound(nums, target);    // 第一个 > target
    if (first == n || nums[first] != target) return {-1, -1};
    return {first, last - 1};                 // [第一个, 最后一个]
}
```

★ **`last - 1` = 最后一个 `== target`**（第一个 `> target` 的前一个）。

### 7.2 搜索插入位置（35）（lower_bound 直接用）

```cpp
int searchInsert(vector<int>& nums, int target) {
    int left = 0, right = nums.size();
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] >= target) right = mid;
        else left = mid + 1;
    }
    return left;      // ★ 不用验证（要的是「插入位置」）
}
```

### 7.3 珂珂吃香蕉（875）（二分答案入门）

| | |
|---|---|
| 答案 | 吃速 `k` |
| 范围 | `[1, max(piles)]` |
| `can(k)` | `Σ ceil(p/k) ≤ h` |

★ **`ceil(p/k)` 的整数写法**：`(p + k - 1) / k`。

### 7.4 1011 送货 / 410 分割数组（同一 `can`）

| | 1011 | 410 |
|---|---|---|
| 答案 | 船容量 | 子数组和上限 |
| `lo` | `max(weights)` | `max(nums)` |
| `hi` | `sum(weights)` | `sum(nums)` |
| `can` | 贪心分段，天数 ≤ D | 贪心分段，段数 ≤ k |

★ **`can()` 几乎一样** —— 都是「贪心累加，超过上限就切」，只判「天数」还是「段数」。

```cpp
bool can(vector<int>& nums, int k, int limit) {
    int segCount = 1;              // ★ 至少 1 段
    long long cur = 0;
    for (int x : nums) {
        if (cur + x > limit) {
            segCount++;
            cur = x;               // ★ 切新段，从当前元素开始
        } else cur += x;
    }
    return segCount <= k;
}
```

★ **`lo = max` 的意义**：保证任何单元素都能单独成段 → 不用特判「单元素超上限」。

## 八、⚠️ 避坑清单

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | **`left = mid` + 向下取整 → 死循环** | 用 `right = mid` 写法；或改向上取整 `(l+r+1)/2` |
| 2 | **闭区间 `right=n-1` 混半开循环 `left<right`** | **统一半开**：`right = n`，循环 `left < right` |
| 3 | `mid = (l+r)/2` 溢出 | `mid = left + (right - left) / 2` |
| 4 | 二分后忘记验证「找不到」| `pos == n \|\| nums[pos] != target`（要「下标」时）|
| 5 | **`can` 里切段时忘了重置累加器** | 切段后 `cur = x`（**不是清零，不是保留**）—— 本人踩坑 |
| 6 | 用 `int` 存累加和 | `long long`（防溢出）|
| 7 | 二分答案 `right = mid - 1` | 应为 **`right = mid`**（mid 可行可能是答案）|

| 34 | 超时（死循环）| 第二段 `left = mid` + 向下取整 |

## 十、一句话总结

> ★ **二分 = 在单调序列上找「翻转点」（第一个满足条件的位置），O(log n)。**
>
> ★ **统一用半开 `[left, right)` + `right = mid`** —— 区间严格缩小，永不死循环。
>
> ★ **铁律：`mid` 向下取整时，只有 `right = mid` 安全；`left = mid` 会死循环。**
>
> ★ **二分答案 = 对「答案空间」二分，条件是 `can(候选)`；骨架同 `lower_bound`。**
>
> ★ **二分找位置，验证判存在** —— 要「下标」时记得 `pos == n || nums[pos] != target`。
>
> **思想：每次排除一半 → O(log n)；判据是「单调性 / 翻转点」，不是「有序」。**
